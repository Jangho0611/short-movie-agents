### 가격 검색 키워드

건축자재 검색에서는 가격 관련 구매 의도가 중요하므로 모든 품목 콘텐츠의 기본 SEO·검색 키워드에 `품목명+가격`을 반영한다.

예시:

- `석고보드가격`
- `MDF가격`
- `합판가격`
- `자작합판가격`
- `각재가격`
- `방부목가격`
- `PF보드가격`
- `아이소핑크가격`
- `단열재가격`
- `창호가격`
- `도어가격`

실제 가격을 알려주지 않는 콘텐츠에서는 제목을 낚시성으로 만들지 않는다. 설명에는 `○○ 가격·대량 구매·납품 상담`, 해시태그에는 `#○○가격` 형태로 자연스럽게 구매 검색 의도를 연결한다.

### 이번 2개 콘텐츠의 검색 키워드

두 콘텐츠 모두 핵심 품목이 석고보드이므로 아래 검색 후보를 공통 적용한다.

- `석고보드`
- `석고보드가격`
- `석고보드구매`
- `석고보드납품`

`석고가 두부에도 쓰인다고요?`에는 아래 키워드를 추가한다.

- `천연석고`
- `천연석고보드`
- `자이석고보드`
- `자이천연석고보드`

`석고보드는 어떻게 벽이 될까?`에는 아래 키워드를 추가한다.

- `석고보드시공`
- `가벽시공`
- `벽체시공`
- `하지작업`

### 향후 품목별 운영

- 품목이 바뀌면 가격 키워드도 반드시 해당 품목으로 변경한다.
- 범용 `건축자재가격`보다 구매자가 실제 검색할 가능성이 높은 구체적인 `품목명+가격`을 우선한다.
- MDF 콘텐츠에서는 `건축자재가격`만 사용하지 않고 `MDF가격`을 우선한다.
- 합판 콘텐츠는 `합판가격`, PF보드 콘텐츠는 `PF보드가격`, 아이소핑크 콘텐츠는 `아이소핑크가격`을 우선한다.
- 별도 데이터로 검증되지 않은 검색량 수치를 문서에 기록하지 않는다.

## 2026-08-20~21 업로드 예정

- 목요일 1편, 금요일 1편으로 각각 업로드할 예정이다.
- 어느 영상을 목요일 또는 금요일에 배치할지는 현재 단계에서 확정하지 않는다.
- 대상 콘텐츠 A: `석고보드는 어떻게 벽이 될까?`
  - 석고보드 벽체 시공 과정 콘텐츠
  - 하지 구조 → 보드 위치 → 고정 → 반복 시공 → 벽면 완성
- 대상 콘텐츠 B: `석고가 두부에도 쓰인다고요?`
  - 황산칼슘의 식품 사용 → 의료용 활용 → 건축용은 식용 아님 → 자이 천연석고보드의 천연석고 원료 메시지
- 플랫폼: YouTube Shorts / Instagram Reels / Naver Clip
- 업로드 직전에 각 플랫폼의 최종 제목·본문·해시태그를 다시 확인한다.
- 각 문안에 해당 품목의 가격·구매·납품 검색 키워드가 포함됐는지 확인한다.
