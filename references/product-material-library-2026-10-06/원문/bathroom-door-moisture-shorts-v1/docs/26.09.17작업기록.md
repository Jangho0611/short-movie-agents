### 1. Scene5 Flow 캐릭터 합성 — 얼굴 뭉개짐 / 실루엣 경계 지저분함

### 17. Git `.git/index.lock` 반복 발생 — 클라우드 세션의 상태 확인 명령이 원인
- 증상: 사용자가 커밋 명령어를 여러 차례 정상 실행했는데도 `fatal: Unable to create '.../.git/index.lock': File exists` 오류로 커밋이 계속 실패, 사용자는 반복해서 같은 명령어를 재실행.
- 원인: 클라우드 세션 쪽에서 상태 확인용으로 실행한 `git status` 계열 명령이 index.lock을 생성했다가, 샌드박스 권한 문제로 그 lock 파일을 정상적으로 지우지 못해 계속 남음 → 이후 사용자의 실제 터미널에서의 모든 git 명령을 차단.
- 해결: 사용자 터미널에서 `rm -f .git/index.lock` 실행 후 재시도 → 정상 커밋/푸시 성공.
