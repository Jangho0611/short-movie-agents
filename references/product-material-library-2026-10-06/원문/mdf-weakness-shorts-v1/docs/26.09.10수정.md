# MDF 약점(원목 비교) 편 — 작업기록

## 주제 및 기획
- 배경: 2026-09-01 에펨코리아 "오래된 가구가 요즘 가구보다 튼튼한 이유" 글(조회 21만, 추천 500+) — "MDF/PB라 요즘 가구 부실하다"는 커뮤니티 논란이 실시간 확산 중인 걸 발견하고 이 흐름 위에서 기획
- 핵심 메시지: MDF가 원목보다 약한 건 사실(강도·습기 모두)이라고 정직하게 인정 → 그럼에도 왜 널리 쓰이는지(표면 균일 → 시트지 마감 우수) 반전 → 실전 팁(피스는 밑구멍부터)으로 마무리
- 허위/과장 없이 정직한 정보 전달 원칙 유지 (Scene 3 물방울 부풀어오름 과장 표현은 영상에서 상징적으로만 쓰고, 실제로는 장기·반복 노출 시 나타나는 현상이라는 걸 보조 주석으로 명시)

## Scene 구성 (최종, 총 35.1초 + 엔딩)
1. **Hook** (5.71초) — "MDF, 원목보다 약하다고요? 맞습니다." / 대산이+실물 패널 캐릭터 합성 이미지, Flow 팔·입 모션
2. **강도** (4.87초) — "먼저 당기거나 휘는 힘엔 원목보다 약해요." / 순수 Remotion 코드 비교 그래픽(당기는 힘/휘는 힘, 원목 vs MDF 바 그래프)
3. **습기** (5.95초) — "그리고 물에 젖으면 절단면부터 부풀어 올라요." / 실물 엣지 누끼 + 대산이 + Flow 물방울 낙하·부풀어오름 애니메이션
4. **그래도 쓰는 이유** (5.33초) — "표면이 균일해서 시트지 마감이 훨씬 깔끔해요." / 실물 표면 클로즈업 → mask wipe → Vertex 생성 인테리어(시트지 마감 몰딩) 이미지
5. **실전 팁** (8.00초) — "팁을 드리면 피스를 바로 박으면 안 됩니다. 밑구멍부터 뚫어야..." / 순수 Remotion 코드 좌우 비교 다이어그램(바로 박기 vs 밑구멍 먼저), Flow로 피스 삽입 애니메이션
6. **엔딩** — 기존 승인 엔딩 재사용 (`scene07-daesan-ending-final.mp4`, `scene07-ending.wav`, `daesanlogo2.png`)

## 워크플로우 특이사항 (이번 에피소드에서 처음 발생)
- **Codex 토큰 소진**으로 세션 중반부터 TTS·ffmpeg·자막·Cover·정리·Git까지 전부 터미널 직접 명령으로 대체 진행 — 이미지 생성(Vertex AI)과 Remotion 코드 애니메이션만 Codex 사용
- macOS Homebrew 기본 ffmpeg에 freetype 없어 drawtext 불가 → Python(PIL)으로 자막 PNG 직접 제작 후 ffmpeg overlay로 대체
- concat demuxer가 해상도/fps 다른 클립(Flow 720x1280 24fps vs Remotion 1080x1920 30fps) 혼합 시 프레임 밀림 발생 → concat filter(scale+fps 통일)로 전환해 해결
- Flow 결과물의 sparkle 워터마크가 패널 모서리선과 겹치는 경우 단순 blur로는 선이 끊김 → 실제 선 기울기를 측정해 패치 이미지를 직접 그려서 오버레이하는 방식으로 해결
- TTS 자연스러운 pause: 문장을 조각으로 나눠 따로 생성 후 무음(0.05~0.5초, 용도별 구분)으로 이어붙이는 방식이 쉼표보다 안정적
- 자막 씬 전환 타이밍은 개별 클립 길이 합산이 아니라 최종 concat 영상에서 실제 프레임 확인한 값을 사용해야 함(fps 변환 시 미세한 길이 차이 발생)
