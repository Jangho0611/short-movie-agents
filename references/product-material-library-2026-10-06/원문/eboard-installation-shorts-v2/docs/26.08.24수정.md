# 이보드 시공 Shorts 최종 수정 기록 — 2026-08-24

## 최종 결과

- 총 S1~S8, 1080×1920, 24fps, 815프레임, 영상 기준 33.958초.
- S1/S3/S5는 승인 Flow, S2/S4/S6/S7은 승인 실사 이미지 기반 Remotion, S8은 승인 대산 브랜드 엔딩을 사용한다.
- 최종 승인 Preview는 `public/references/eboard-installation-full-preview-v12.mp4`, 최종 보존본은 `public/final/eboard-installation-shorts-final.mp4`다.

## 이미지·Flow 시행착오와 해결

- S6 초기 결과는 네바리와 메쉬테이프의 길이 및 작업 위치가 좌우에서 달랐다. 부분 시공 장면을 늘리는 방식으로는 해결되지 않아, 화면에 보이는 조인트의 TOP부터 BOTTOM까지 자재가 이미 연속 시공된 완료 상태로 다시 정의했다.
- S6 헤라는 자재를 새로 붙이거나 끌어내리는 도구가 아니라, 이미 부착된 자재의 중앙을 압착·정리하는 상태로 고정했다. 좌우 헤라 중심, 손 위치, 라벨 높이와 자재 시작·끝 높이도 같은 선으로 맞췄다.
- S7 최초 후보는 단순히 이보드가 부착된 상태여서 최종 결과 컷으로 부족했다. 실제 완료 기준은 조인트와 네바리/메쉬테이프 보강 이후 도배 또는 페인트 마감까지 끝난 상태다. 최종 S7은 도배 완료 컷을 사용한다.

## S3 Flow 시행착오

- Start Image hold가 재단 Scene 진입 직후 정체감을 만들었다. 최종 구조에서는 Start Image hold를 0프레임으로 하고 Flow frame 0부터 즉시 재생한다.
- 승인 Flow는 0~79프레임만 사용해 후반 안전자 이동을 제외했다. 마지막 freeze/hold도 0프레임으로 제거했다.
- 칼질 움직임이 살아 있는 상태에서 S3→S4 전환을 시작한다. 확정 transition은 16프레임, 약 0.667초다.

## Transition 교훈

- 모든 Scene에 같은 짧은 dissolve를 넣는 방식은 연결감을 높이지 못했고, 구도가 크게 다른 Scene을 겹치면 오히려 AI 영상처럼 보였다.
- 특히 S3는 `칼질 → 정지 → 전환`보다 마지막 움직임 위에서 다음 공정이 드러나는 구조가 자연스럽다.
- Flow 원본의 자연스러운 움직임을 TTS나 전환에 맞추려고 임의 trim, freeze, 반복하지 않는다. S1은 승인 원본 96프레임 전체를 playbackRate 1.0으로 사용한다.

## TTS 시행착오와 최종 원칙

- 초기 통합 TTS는 문장별 억양이 이어지고 `~합니다`가 반복돼 AI 안내방송처럼 들렸다. Scene별 독립 TTS로 전환하고 실제 무음을 타임라인에서 확보했다.
- S1은 `이보드` 뒤 쉼이 없으면 `이보드그냥`처럼 들린다. 최종 S1은 speakingRate 0.89와 약 0.324초 내부 pause를 사용한다.
- S6은 `네바리로` 뒤를 명확한 의미 경계로 분리해야 한다. 최종 S6은 약 0.507초 pause를 확보했다.
- Scene 전환 직전과 직후 발화가 붙지 않도록 영상 구조 안의 여유를 사용한다. Flow를 TTS에 맞춰 자르거나 playbackRate를 바꾸지 않는다.
- 효율적인 순서는 영상 동작과 Scene timing을 먼저 확정한 뒤 마지막에 TTS 발화와 호흡을 다듬는 것이다.

## DESIGN.md 시행착오

- 초기 조립에서는 DESIGN.md 적용이 누락됐다.
- 이후 Notion/Airbnb 원칙만 적용해 scrim, shadow, subtle scale 중심으로 후처리했으나 사용자가 의도한 기존 대산 Shorts 정보 디자인과 달랐다.
- v11의 Green underline과 432px dark scrim 역시 의도와 달라 폐기했다.
- 사용자가 말한 DESIGN.md 적용은 기존 Shorts처럼 자막 뒤에 컬러 정보 배경 블록을 두고 Scene 메시지를 하나의 정보 면으로 읽히게 하는 시스템이었다.
- 실제 구현을 확인한 프로젝트는 `MDF_vs_PB_vs_Plywood`, `pf-vs-xps`, `window-condensation-shorts-v1`이다.
- 최종 실질 기준은 `design_walletvy.md`이며, Notion/Airbnb는 정보 위계와 실사 보존 원칙만 보조 참고했다.

## 최종 DESIGN 규칙

- S1: 대산 Green 정보 블록.
- S2~S5: warm beige 정보 블록.
- S6: 축소 beige 본문 블록과 `도배용 / 페인트용` 좌우 라벨.
- S7: 가장 절제된 beige 결과 블록.
- S8: 기존 승인 엔딩 무수정.
- Pretendard 800, radius 20px, thin border, soft shadow를 사용한다.
- 블록은 14프레임 fade와 `translateY 24px → 0` settle로 진입한다.
- 과도한 scrim, outline, underline accent는 사용하지 않는다.

향후에는 `기획 → 승인 미디어 → Remotion 조립` 전에 DESIGN.md를 확정하고, 최소 한 Scene에 실제 디자인 Preview를 적용해 사용자 승인을 받은 뒤 전체 Scene으로 확장한다. 영상 완성 직전에 DESIGN.md를 뒤늦게 적용하지 않는다.
