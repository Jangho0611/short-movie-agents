# 26.08.07 작업 기록

## 프로젝트 목표와 제작 원칙

- 소송각재 정보를 설명하는 세로 9:16 Remotion Shorts를 제작했다.

### 제작 과정과 캐릭터 통일

- Scene 1은 각재 형상, 라벨 중복, 목재색, 캐릭터 형태를 단계적으로 수정했다. v4에서 천연 목재색과 최종 캐릭터가 안정되어 canonical character로 확정했다.
- 캐릭터는 검정 hand-drawn ink 외곽선, 회색 작업복, 옅은 ivory-gray 얼굴, 중립적 단순 표정의 작은 editorial/chibi 비율이다.
- 기준 팔레트는 body `#636361`, face `#E4DFD9`, outline `#1E1E1E`, eyes/mouth `#0A0A0A`이다.
- 체형은 상대적으로 큰 머리와 짧은 몸통·팔·다리의 compact proportions이며, 화면 높이 약 18~20%, 최대 21%를 기준으로 잡았다.
- Scene 2 캐릭터는 화면 약 25% 수준으로 커졌다. Reference 기반 geometry/크기 수정을 시도했지만 원하는 수준으로 축소되지 않았고, 시간 대비 효율을 고려해 최종 수용했다.
- Vertex reference edit는 원본 일부만 고정 수정하는 방식이 아니라 전체 이미지를 다시 해석할 수 있어 색상 drift와 geometry 변화가 생길 수 있었다.
- HEX 프롬프트만으로 정확한 색을 고정하기 어려웠다. Scene 2 얼굴과 Scene 3의 세 등장 캐릭터 얼굴은 추가 API 호출 없이 `scripts/local-face-recolor.mjs`로 local pixel recolor하여 통일했다.
- Scene 4는 생성 과정에서 생긴 불필요하거나 이상한 텍스트를 로컬로 정리하고 `scene04-vertex-reference-v6-cleaned.png`를 최종 사용했다.
- 결론적으로 정확한 단순 색상 수정은 reference edit보다 local recolor가 더 안정적이었다.

### 시행착오와 처리

- Scene 2는 후반부에서 캐릭터 손이 떨어지고 표정과 라벨 등이 변했다. 안전 구간까지만 trim하고, 긴 TTS가 끝날 때까지 마지막 안전 프레임을 hold했다.
- Scene 3은 `!` / `?` 기호가 Veo에서 흔들리거나 변형됐다. Static/fixed 방식으로 보완한 `scene03-veo-final-fixed-v2.mp4`를 최종 사용했다.
- Scene 4는 약 2.5~2.7초 이후 이미지가 깨졌다. 0~2.375초 안전 구간만 trim하고 이후는 마지막 안전 프레임을 hold했다.
- Veo는 글자와 기호를 고정하는 데 약하다. 이상 구간을 다시 생성하기보다 local overlay, trim, hold가 더 빠르고 안정적인 경우가 있었다.
- 안전 구간 이후 영상을 반복 재생하지 않아 Scene 2/4의 문제 구간이 다시 노출되지 않도록 했다.

## 자막 제작과 시행착오

- STT나 외부 API를 사용하지 않고 확정 대본으로 Scene 1~5 subtitle event를 직접 구성했으며, 최종적으로 Scene 5 subtitle은 제거했다.
- 최초 하단 자막은 Shorts/Reels UI에 가릴 위험이 있어 `bottom: 240px`을 시도했다. 이 과정에서 자막뿐 아니라 여백/전체 레이아웃이 올라가는 퇴보가 확인되어 영상 wrapper를 원상복구하고 독립 overlay만 이동하도록 수정했다.
- `bottom: 150px`에서는 영상 레이아웃은 유지됐지만 기존 하단 gradient/background와 텍스트 위치가 분리되어 어색했다. 이에 하단 자막 방식을 폐기했다.
- 상단 흰 여백 방식으로 전환하면서 gradient/background를 완전히 제거하고 영상의 위치, 크기, scale, crop을 유지한 채 absolute subtitle overlay만 사용했다.
- 공통 `top: 130px`은 Scene 2와 Scene 4의 그림/선과 겹쳤다. Scene별 상단 사용 영역이 달라 최종 위치를 개별 분기했다.
- 최종 위치: Scene 1 `top: 130px`, Scene 2 `top: 65px`, Scene 3 `top: 130px`, Scene 4 `top: 65px`, Scene 5 subtitle 없음.
- 관련 최종 파일은 `src/components/SceneCaptions.tsx`이며, Scene 5 subtitle 제거 이력은 `src/components/SosongFinal.tsx`에 반영됐다.
- 핵심 교훈: 자막 위치 수정 시 부모 Scene/video wrapper의 padding, margin, position을 건드리지 말고 독립 absolute overlay만 움직인다.

## 렌더 과정과 최종본

- Codex 환경의 Remotion render 시도는 composition 오류가 아니라 sandbox filesystem/process 실행 제한으로 실패했다. 확인된 오류는 parent-directory access denied와 render connection 조기 종료였다.
- `SosongFinal` 등록과 소스 코드/타입 구성은 정상으로 확인됐다.
- 실제 최종 렌더는 사용자 PowerShell에서 수행했다.
- `v1`, `v2`, `v3`는 자막 위치와 레이아웃 시행착오를 비교한 중간본이다.
- 최종 승인본은 `output/sosong-final-v4.mp4`이다.
- 2026-08-07 오후 5:22:41 기준 파일이 실제 존재하며 크기는 3,459,733 bytes이다.
- 최종 파일 metadata: 720×1280, 24fps, 813 video frames, audio stream 포함. 컨테이너 duration은 약 33.899초이다.
