# 추가 수정 (26.07.27, 2차): ProductBoard SVG 아이소메트릭 전환
피드백: 기존 CSS 박스형 ProductBoard가 "직사각형 오브젝트"처럼 보여 XPS/PF를 한눈에 인식하기 어려움 → 제품성 강화 요청.

## 변경 내용
- `src/components/ProductBoard.tsx`를 CSS 사각형에서 **SVG 아이소메트릭 박스**(top/front/side 3면 + 두께)로 전면 교체.
  - top면(마름모) + front/side 두 면(두께만큼 내려오는 사각형/평행사변형)을 좌표 계산으로 직접 구성(30° 아이소메트릭, 폭 대비 두께 13%).
  - Ambient Shadow: 보드 하단에 `feGaussianBlur` 처리된 반투명 타원.
  - Bevel Highlight(상단 모서리 밝은 stroke) + Edge Highlight(면 경계 모서리) + 하단 음영 stroke.
  - XPS: 선명한 핑크 계열 그라디언트(top) + 18~20% 어두운 front/side + 압출 결(대각선 hairline 패턴, `<pattern>`+`clipPath`).
  - PF: 은색 알루미늄 그라디언트(top, 대각선 스페큘러 밴드) + 브러시드 메탈 패턴 + side면을 3개 폴리곤 밴드(알루미늄/연핑크 심재/GF)로 분할한 실제 절단면 표현.
  - `edgeEmphasis`(0~1): side면 코어(심재) 비중 0.5→0.78로 확대 + 심재 채도(lerpColor로 desaturated→vivid pink) + 밴드 대비 강화. 폴리곤 좌표(각도/크기)는 emphasis와 무관하게 항상 고정 — 형태 흔들림 없음.
  - 외부 이미지 에셋 없음(전부 SVG 벡터).
- 기존 `variant`/`width`/`height`/`style`/`edgeEmphasis` prop 인터페이스를 그대로 유지 → `Scene3Reversal.tsx`, `Scene4Bridge.tsx`, `brief.ts`는 수정 불필요(호출부 무변경).
