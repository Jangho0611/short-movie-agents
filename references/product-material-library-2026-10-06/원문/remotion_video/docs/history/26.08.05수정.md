# 26.08.05 수정 기록

## 프로젝트별 폴더 구조 1차 통합

- 기존에는 PF보드 vs XPS가 `main` 브랜치 루트에, MDF·PB·합판 프로젝트가 `mdf-pb-plywood` orphan 브랜치 루트에 저장되어 있었다.
- 완성 영상 프로젝트 3개를 확인했다: `pf-vs-xps`, `mdf-density`, `mdf-pb-plywood`.
- `mdf-density`는 로컬에 소스와 작업 기록 및 최종 렌더가 있으나 GitHub에는 저장되지 않은 상태였다.
- 완성 프로젝트 3개를 `projects/<project-name>/` 아래의 독립 프로젝트 구조로 전환했다.
- 각 프로젝트의 독립 `package.json`과 `package-lock.json`을 유지하는 단순 멀티프로젝트 방식을 채택했다.
- npm workspace는 이번 통합에 적용하지 않았다.
- `node_modules`와 `out`은 통합 및 Git 추적 대상에서 제외했다.
- 원본 로컬 프로젝트 폴더는 삭제하거나 이동하지 않고 유지했다.
- 범용 `template` 프로젝트 통합은 다음 작업으로 보류했다.
- 최종 렌더 영상 MP4는 이번 Git 변경에 포함하지 않았다. 프로젝트 복원에 필요한 생성 영상 에셋은 해당 프로젝트의 `public` 아래에 보존했다.
- `out` 아래의 최종 렌더 MP4는 계속 제외하되, `projects/mdf-density/public/generated/mdf-density/` 아래의 장면 입력 MP4 39개는 재렌더링에 필요한 복원 자산으로 Git에 포함했다.
- `mdf-density`는 기존 Git 저장소가 없었으므로 이번 통합 변경이 최초 Git 이력이 된다.

## MDF·PB·합판 프로젝트 출처

- 원본 브랜치: `origin/mdf-pb-plywood`
- 원본 커밋: `044a7420d567ee5ed08d543e8928a09f28985d32`
- 반입 방식: `git read-tree --prefix=projects/mdf-pb-plywood/ -u origin/mdf-pb-plywood`
- 원본 브랜치는 삭제하거나 수정하지 않고 유지했다.
- 통합 브랜치에서는 원본 커밋의 파일 스냅샷을 `projects/mdf-pb-plywood/` 아래에 보존하며, 무관한 부모 이력은 연결하지 않았다.
