## 핵심 내용

영림 목문틀 발주 시 일체형과 분리형의 구조와 바수별 발주 기준을 설명한다.

대산 실제 영림 발주 기준:
- 일체형 / 분리형 모두 발주 가능
- 실제 발주는 분리형을 많이 선택
- 일체형은 최소 60바부터 가능
- 일체형은 외도어 타입 / 고바이 타입 선택 가능
- 분리형은 최소 100바부터 가능
- 100바 분리형은 가스켓 적용 불가
- 가스켓 적용은 110바부터 가능
- 100바 미만에서는 분리형이 아닌 일체형으로 발주

## 최종 Scene 구성

1. Hook — 목문틀 일체형 vs 분리형
2. 분리형 — 문틀 + 스토퍼 별도 구성
3. 일체형 — 외도어 / 고바이 디자인 및 최소 60바
4. 실제 발주 — 분리형을 많이 선택하지만 바수가 작으면 타입 제한
5. 분리형 기준 — 100바 / 가스켓 110바
6. 결론 — 100바 미만 일체형, 바수 + 타입 확인
7. Canonical 대산 본사 전경 Ending
