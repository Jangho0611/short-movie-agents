# 2026-10-19 도어클로저 편 제작 준비 / TTS v1

## 사실과 미확인 사항
- 사용자 확인: 실제 A/S 접수 현장 영상이며 해당 문에 도어클로저가 없다. 문 닫힘 불량으로 접수됐다.
- 미확인: 외풍/압력 차이가 직접 원인인지, 하드웨어 이상 유무, 클로저 설치 후 해결 여부. 미설치를 유일 원인으로 단정하지 않는다.
- 최신 사용자 승인 TTS/자막 그대로 적용. 기획과 시리즈 자산은 DoorMaster 기준. 대산이 기본 PNG는 복사하되 본 시리즈에 사용하지 않는다.

## Slim Copy
- 기존 hidden-door generate_tts.py 바이트 동일 복사. Google ADC 기존 인증 사용. 인증파일 프로젝트 복사 없음.
- Alnilam / speakingRate 1.00 / pitch 미지정 / plain text. A/S 원문 유지. 발음·톤·자연스러움은 기계적 PASS 판정하지 않음.
- Canonical 엔딩 전체 직접 의존 자산과 source, 로고/폰트, 승인 DoorMaster 간판 v2, package/lockfile 복사. 엔딩 source는 프로젝트 내부 staticFile prefix만 변경.
- node_modules 복사/설치 없음. TTS .venv만 생성하고 requirements-tts.txt 기록. 신규 .git/origin 없음.
- 원본 영상 A/B 복사 전후 SHA256 PASS. Downloads 원본 변경 없음. docs/slim-copy-sha256.json 참조.
