# Preview v2 검토

수정: Scene 1~5 시리즈 간판 및 EP.02 제거. 검정 자막 박스 제거, 짙은 글자와 우드톤 강조로 변경. 설명형 문구, 의미 단위 시작 프레임, 최대 2줄 유지. Scene 3·4는 비워진 상단에 자막을 배치해 제품을 가리지 않음. Scene 3 사진 표시 영역 확대, 사진의 2.5% 미세 확대 제거. 사진 순서와 컷 프레임 26/44/64 유지.

## Scene 3 원인과 조치

v1은 디코딩 오류가 없어도 실제 영상 프레임이 잘못 렌더되어 있었다. 개별 Scene 3의 20·30프레임에 사진과 간판이 타일처럼 반복되는 화면 확인. 전체 Preview에서는 Scene 3 내부 1·10프레임 등에 비정상 변화 확인. 프레임 수 127 및 PTS 간격 0.033333/0.033334초는 정상. v1은 Remotion에서 직접 전체 렌더했으며 FFmpeg concat을 사용하지 않았다.

원본 확장자는 JPG이나 Pillow가 MPO로 인식하고 EXIF orientation=6이다. 3장은 5712×4284, 제품 사진은 4032×3024. v1은 단일 Img의 src 교체와 프레임별 소폭 scale을 사용했다. 확인된 실패는 인코딩 전 화면 렌더/합성 손상이다. MPO 디코더, GPU/브라우저 합성, 동시성 중 단일 내부 원인은 분리 검증하지 않았으므로 확정하지 않는다.

원본을 보존하고 EXIF 회전을 반영한 1200×1600 일반 JPEG 렌더 사본 4개를 public/assets/images/*-render-v2.jpg에 저장. 4개 Img를 고정 마운트하여 컷에서 opacity만 전환. 정지 사진의 scale 제거. swangle 소프트웨어 그래픽, concurrency=1로 렌더.

v2 개별/전체 Scene 3 각각 127프레임 전수 비교: 사진 영역의 급격한 변화는 26/44/64프레임만 검출. 예상 외 변화 0개. 샷 내부 최대 평균 절대 픽셀 차이 0.039 미만(180×320 축소 분석, RGB 0~255). 개별/전체의 사진 표시 순서와 전환 프레임 동일. 정지 사진 구간의 반복 프레임은 의도된 hold이며 프레임 누락으로 판단하지 않음. 비교 프레임 육안 확인에서도 타일형 손상 없음. 이는 출력 프레임 검사이며 사용자 기기에서의 체감 부드러움 자동 PASS는 아님.

## 보존 및 QA

영상 6개 모두 1080×1920 / 30fps / H.264 / AAC, 전체 오디오·영상 디코딩 오류 없음. Scene 영상 길이: 3.066667 / 5.400000 / 4.233333 / 5.000000 / 5.233333초. 전체 영상 28.600초, AAC 패딩 포함 컨테이너 28.650667초.

승인 WAV 5개 SHA256 일치. Scene 2 -1.5dB 게인 유지, 추가 보정·속도·피치 변경 없음. 발화 시작 및 문장 전환 타이밍은 v1과 같음. 청취를 통한 싱크 및 자연스러움 최종 승인은 사용자 확인 필요.

엔딩 직접 의존 소스·자산과 간판 보존 세트 20개 해시 일치. 프로젝트 내부 승인 영상으로 엔딩 170프레임 유지. 최종 영상의 재인코딩 때문에 바이트 동일본은 아니며 SSIM 결과는 preview-v2-ending-ssim.log에 기록. 엔딩 디자인/전화번호/로고/오디오를 수정하지 않음.
