# Scene 4 Preview v2 시작 오류 QA

2026-11-06

## 확인된 원인과 발생 시점
v1의 0-based 1번 프레임(두 번째 프레임), 0.033333~0.066667초에 제목이 여러 위치에 반복되고 카드가 사라진 비정상 화면이 삽입됨. 0번 및 2번 프레임은 정상. 0~45번 프레임 인접 비교에서 0→1, 1→2만 큰 차이(평균 채널 차이 약12.52, 차이20 초과 픽셀 약98,800개). 그 밖의 초기 프레임 변화는 압축 오차 수준.

소스의 초기 0~1.5초에는 표시 전환·마스크·움직임이 없음. 카드·제목은 고정, 문서 아이콘 불투명도0.18, 나머지 공개 값0. 따라서 Fade 조건으로 설명할 수 없는 출력 프레임 불연속임. Chrome compositor/캡처/인코더 중 어떤 내부 단계가 원인인지는 확정하지 않음. 재렌더 시 동일 문제가 재발하지 않는다는 보장은 없음.

## 최소 수정
Remotion 소스나 레이어 변경 없음. FFmpeg에서 v1의 frame1만 제거하고 정상 frame0을 한 번 더 배치. setpts=N/(30*TB)로168프레임 유지. H.264 CRF0 무손실 재인코딩으로 정상 디코딩 픽셀 보존. 원본 v1 AAC 전 스트림을 별도로 stream copy하여 완전 보존. 승인 MP3 편집 없음.

재현 필터: select='not(eq(n,1))',loop=loop=1:size=1:start=0,setpts=N/(30*TB)
영상만168프레임 출력 후 v1 오디오 전체를 별도 mux해야 말미 패킷까지 보존됨.

## 검증
- 최종 v1/v2 전체168프레임 YUV420 디코딩 바이트 비교: 변경 프레임은1번만. 나머지167프레임 완전 동일.
- v2 frame1은 v1 frame0과 완전 동일. 0/1/2 비교 이미지 직접 확인: 반복 제목·카드 소실 제거.
- AAC 전 패킷 ADTS 추출 바이트 동일. TTS 원본 SHA256 ed1894a3f98116705244227f502ec9157496af4bd0dbe39bb63ca52eede2580e 유지.
- 기존101개 소스·음원·이미지·영상 기준 해시 변경 없음. Scene1~3 및 기존 Scene4 소스 보존.
- H.264/AAC,1080×1920,30fps,168프레임,영상5.600초. AAC/컨테이너5.653333초.
- 전체 영상·오디오 디코딩 오류 없음.
- QA 이미지 위 v1, 아래 v2 / 각0,1,2번 프레임.

## 승인 및 한계
검출한 단일 프레임 깜빡임은 제거됨. 전체 디자인·설치도·작업 공간 모션은 정상 프레임 완전 동일성으로 보존 확인. 실기기 플레이어에서의 재생 및 실제 청취는 사용자 확인 필요. 무손실 H.264의 플레이어별 호환성은 미확인. 전체 영상 조립 미실시. 소스 내부 원인이 확인된 것으로 주장하지 않음.
