## 확인
실제 모바일 QA 및 2→3 연결 비교 이미지를 육안 확인. 제목/라벨/질문 겹침이나 잘림 없음. 상단에서는 좌우 연결 철물과 문짝의 관계가 읽힘. 하단은 상부 철물이 외관에 보이지 않는 예시. 좌측 문짝 두께가 얇고 열린 방의 상당 부분이 제외되어, 하단 크롭만 보면 문짝 식별이 2-B 전체 이미지보다 약함. 이 차이가 허용되는지 사용자 시각 승인 필요.
두 컷 사이 전후 화살표 없음. 서로 다른 구조 예시 및 제품별 확인을 명시. 노출 여부를 근거로 접근/교체 가능성 단정하지 않음. 같은 현장의 전후로 오인할 가능성 자체를 배제하지 않음. 댐퍼·분해 방향·치수·점검구·철거 범위 미표시. 체크리스트의 질문이 접근 조건을 전달하며 실제 경로 자체는 사진으로 검증하지 않음.
Scene 2는 사건 결과로 끝나고 Scene 3은 두 이미지와 점검 질문을 동시에 제시. 모바일 실기기·플랫폼 오버레이, 모션/싱크, 무설명 시청자 이해도 테스트 미실시.
