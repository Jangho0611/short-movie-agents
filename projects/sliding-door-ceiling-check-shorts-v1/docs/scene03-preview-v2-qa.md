- 실내 전체와 개구부를 보여주므로 기존 노출 철물 중심 Scene 1·2와 구도 차별화됨.
- 대표 프레임에서 문짝과 열린 통로가 구분되고 문 상단이 보임.
- 문구와 포인트/긴 선·물음표로 두 메시지를 구분. 그래픽이 문짝이나 상단 구조를 덮지 않음.
- 대표 축소 화면에서 문구 판독 가능. 실제 휴대폰 재생 및 영상 전체의 시각적 자연스러움은 사용자 승인 필요.
- 배경의 기존 구조 QA 미통과 사항은 미해결: 실제 레일 위치, 주행 틈 깊이, 문짝이 전체 개구부를 가릴 수 있는 관계, 실제 유지보수 접근 가능 여부는 검증하지 않음.
- 노란 선은 확인할 상부 위치의 개념적 안내이며 실제 레일·점검구 표시가 아님. 얇은 선의 모바일 주목성은 사용자 검토 필요.
