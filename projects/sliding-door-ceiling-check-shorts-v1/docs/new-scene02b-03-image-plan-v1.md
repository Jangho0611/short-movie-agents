## 세 컷이 말하는 것
2-A: 어느 구조를 이야기하나(승인본 그대로). 2-B: 완성 마감에서는 철물이 겉에서 보이지 않을 수 있다(설명 예시). 2-C: 이 현장에서는 실제로 마감재를 철거하고 다시 공사했다(사용자 제공 사실). 사진이 사건 결과를 증명하는 것처럼 붙이지 않는다.

## 2-B: 향후 생성 승인 시 1장
1080×1920 세로 구도 목표. 기준 원본 scene01-before-ai-v3-candidate.png는 조명·질감·약한 사선 시점의 참고로만 사용하고 마감판을 이미지 위에 덧대지 않는다. 처음부터 마감이 완료된 별도의 실내 장면으로 구성한다. 2-A보다 한 발 뒤에서, 문짝 상단과 왼쪽 측면의 두께, 일부 열린 출입구의 안쪽 벽이 한눈에 보이게 한다. 천장 아래면과 부드러운 접촉 그림자를 화면 중앙 부근에, 문짝 몸체를 하단에 둔다. 문짝이 개구부 앞을 따라 지나가는 관계가 읽혀야 한다. 상부 레일·호차·댐퍼는 비노출. 내부를 그리지 않는다. 천장에 인위적인 헤더, 가짜 점검구, 분리형 판 이음선, 화살표·문자·로고 없음. 문짝이 벽과 붙어 보이거나 별도 판이 떠 보이면 불채택.
2-A에서 하드 컷. 두 사진의 윤곽을 정렬하거나 모핑하지 않는다. 자막은 밝은 여백에 ‘천장 마감재가 / 교체 작업을 방해’, 작은 ‘구조 예시’. 그림은 가려진 외관만 설명하고 교체 작업 방해는 해당 현장의 진술이다.

## 2-C: 이번 단계 제작
2-B와 같은 사진을 유지하지 않고 결과 문구에서 독립 타이포 컷으로 전환. 상단 ‘대산 현장 사례’, 중앙 ‘결국 마감재 / 철거·재공사’. 사용자 제공 사실 범위만 사용. 비용·철거 범위·원인 책임 미표시. src/NewScene02ResultV1.tsx. public/assets/images/new-scene02-result-v1.png (1080×1920), new-scene02-result-v1-qa.png (360×640).
실제 축소 출력 확인: 두 줄 판독 가능, 강조 밑줄이 글자와 겹치지 않으며 ‘철거·재공사’가 가장 큼. 상단 출처 표식은 보조 크기. 기기별 UI 가림과 실제 영상에서의 인지 시간은 미검증.

## Scene 3: ① 외관 비교 + ② 질문, 별도의 정비 상태 이미지 없음
① 승인 원본의 레일 크롭(x=0,y=510,w=941,h=750)과 승인될 2-B의 마감 외관을 비교하면 설치 위치를 이해하기 쉽다. 같은 현장의 전후라는 오해는 별도 예시 라벨 및 화면 분리로 방지.
② 한 사진에 질문만 얹으면 기술적 위험은 낮으나 2-B와 같은 화면이 반복되고 설치 위치를 놓치기 쉽다.
③ 별도 생성한 전후 쌍은 실제 정비 접근 조건을 입증하지 못하며 문짝·마감 원근이 바뀔 위험이 높다. 미채택.

추천: 단일 세로 화면의 위쪽에 승인 레일 크롭(두 호차와 문짝 상단 유지), 아래쪽에 신규 2-B의 문짝 측면·마감 경계를 함께 포함하는 크롭. 위는 ‘부품이 들어갈 자리’, 아래는 ‘마감 뒤에도 손볼 수 있을까?’. ‘나중에 손과 공구가 닿고’에서 아래 사진에 시선 전환. ‘부품을 꺼낼 경로도’에서 ‘손과 공구가 닿는가? / 부품을 꺼낼 수 있는가?’를 아래 사진 바깥 여백에 표시. 작은 ‘각각의 구조 예시 · 제품별 접근 방식 상이’. 실제 반출 화살표·작업 반경·치수·합격 표시 없음. 아래 사진을 ‘접근 확보 상태’라고 부르지 않는다. 같은 이미지 반복은 2-B의 단독 사건 설명과 Scene 3의 상하 비교로 구분.
향후 출력 QA: 360×640에서 두 사진 모두 문짝으로 읽히는지, 자막이 경계와 호차를 가리지 않는지, ‘각각의 예시’가 읽히는지 확인. 두 예시를 쌍으로 배치해도 전후로 오해되면 동시 비교 대신 명확한 단컷 전환과 ‘별도 구조 예시’를 사용.
검증되지 않은 사항: 댐퍼 위치·분리 방향·고장 원인·마감 철거 범위·실제 손/공구 접근 및 반출 조건. 접근이 검증된 상태 자체를 보여주려면 동일 제품의 확인된 정비 사진 또는 제조사 근거 필요. 생성 이미지는 대체 근거가 아님.
