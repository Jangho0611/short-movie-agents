## 구성
원본 전체 이미지를 고정 배경으로 사용. 전면(베이지), 하부(청록), 슬롯(짙은 띠), 슬롯 가장자리 안내선 분리. 원본 문짝을 동일 좌표/배율로 슬롯 아래에 clip 재표시. 원본 픽셀 직접 편집 없음. 941×1672 원본을 전체 화면 크기로 표시한 리샘플링은 있음.
좌표는 원본 이미지 공간 단위이며 시공 치수가 아님. 위치는 maskLayout 객체에서 독립 수정 가능.

## 시각 QA
1. 레일/호차: 원본 보존 및 가림 레이어만 추가, 위치 변경 없음.
2. 철물/브래킷: 전면 레이어로 가려짐.
3. 문짝 상단: 원래 상단과 체결부가 가려짐. 문짝 위치 자체는 동일.
4. 문짝 몸체: 슬롯 아래에서 연속되어 보이나 슬롯의 후방 가장자리/깊이 표현 미흡. 조건부.
5. 간섭: 실제 치수/주행 검증 안 함. 경계가 접착/관통처럼 보이는지 사용자 판단 필요.
6. 슬롯: 어두운 띠로 읽힐 가능성 존재. 양쪽 가장자리와 내부 깊이 분리가 충분하다고 판정하지 않음.
7. 원근: 상단은 천장 경계, 하단은 문짝 경계를 따르는 초안이라 기울기 차이가 큼. 일관된 원근 승인 보류.
8. 천장 연결: 상단 경계는 연결되나 전면 면적이 넓고 쐐기형으로 읽힐 수 있음.

결론: 구조 검토용 후보 출력 완료, 구조 QA 승인 보류. 재질 완성 이전에 전면 하단 기울기 및 슬롯 후방 가장자리 설계 수정 필요. 기존 파일 덮어쓰기/삭제 없음. 사용자 검토 대기.
