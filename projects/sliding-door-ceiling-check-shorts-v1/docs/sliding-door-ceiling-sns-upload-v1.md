## 4. SNS 가이드 준수 QA

- 저장소 공통 SNS 가이드 v1.6 적용. YouTube는 제목·설명·고정댓글, Instagram은 설명·고정댓글, 클립은 하나의 통합 본문으로 구성했습니다.
- YouTube·Instagram은 가이드의 홍보 블록과 위아래 구분선을 그대로 사용하고 앞뒤에 빈 줄을 두었습니다. 두 설명에 대산과 daesan.ai가 지정된 문구로 들어가며, Instagram 계정명은 생략했습니다.
- 세 플랫폼의 해시태그는 슬라이딩 도어 → 건축자재 → 대량구매 → 슬라이딩 도어 가격 → 도어 댐퍼 순서로 각 5개입니다.
- 클립은 첫 문구까지 포함해 프로젝트 기준 300자 이내입니다. 현재 네이버 공식 안내는 클립 동영상 설명 최대 3,000자, 해시태그 최대 5개입니다. 사이트명은 일반 텍스트로 표기했습니다. [네이버 클립 고객센터](https://help.naver.com/service/30048/contents/24422?osType=COMMONOS)
- 철거·재시공은 해당 현장의 결과로 한정했습니다. 세 플랫폼 모두 제품별 확인 사항을 안내합니다.
- 문구 QA 완료. 실제 게시 전 사용자 최종 승인 대기.
