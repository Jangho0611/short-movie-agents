# Scene 2-B v2 | 시각 승인 대기
생성 1회. 승인 상부 원본을 재질/시점 참고로 사용. v1 변형 없음. 원본 종횡비에 가까운 세로형을 1080×1920 PNG로 납품. 두 비교판은 각 컷 360×640으로 평가.
- 생성 화면(941×1672 표시 기준)에서 문짝 앞면의 왼쪽 위·아래 약 (234,436)/(234,1346), 오른쪽 위·아래 약 (575,453)/(575,1326). 양 변 평균 높이 약892px, 앞면 폭 약341px: 투영 비율 약2.61:1. 목표 2.41보다 약8% 길쭉. v1은 같은 표시 기준 약1.44:1. 촬영 원근을 보정한 실측값 아님.
- 문 중심 부근에서 문 높이/같은 벽의 바닥~천장 경계 높이 추정 약81%. 설계 기준 2050/2400은 약85%. 문 위 마감 띠는 예시 비례보다 높게 읽힘. 35~40mm 두께는 검증 불가.
- 한 장의 문짝과 왼쪽 개구부, 옆면과 매입 손잡이, 바닥 경계가 식별됨. 오른쪽 벽 여유와 가는 그림자가 보이나 문짝이 벽과 거의 같은 면에 보임. 노출형 또는 포켓형 여부, 실제 이동 및 완전 폐쇄 여부를 판단할 수 없음.
- 마감이 연속적이며 상부 철물, 점검구·탈착판·작업자·파손·텍스트는 보이지 않음. 위쪽은 천장 자체보다는 개구부 위 벽/상부 마감으로 읽힘. 내부 레일 위치, 교체 불가, 실제 현장 사례의 증거가 아님.
- 무광 웜화이트와 자연광, 약한 사선으로 2-A와 톤이 이어짐. 2-A 대비 후퇴한 별도 시점. 현저한 광각 뒤틀림 없음. 모바일에서 문이 벽과 구분되나 좌측 두께와 문 위 음영은 가늘다.
- 외관용 조건부 후보. 같은 현장 전후로 연결하지 말고 별도 구조 예시로 표시. 재생성 없이 사용자 시각 판단 대기. LOCK 파일 변경, Scene 3/TTS/영상 제작 없음.
