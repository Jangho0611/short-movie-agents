# Scene 2-B 마감 외관 v1 | 시각 승인 대기
승인 상부 구조 원본 scene01-before-ai-v3-candidate.png를 이미지 Reference로 사용한 1회 생성. 생성 원본 941×1672 보존, 프로젝트 납품 PNG 1080×1920 리샘플링. 이미지 내부 텍스트 없음. QA 비교본은 각 360×640. 2-A·2-C는 읽기 전용으로 취급.

- 왼쪽에 실내가 보이는 개구부, 문짝의 매입 손잡이, 왼쪽 측면과 바닥 그림자가 보여 고정 벽체와 구분됨. 모바일에서는 왼쪽 두께가 가는 띠로 약해지지만 여전히 손잡이와 개구부가 보임.
- 문짝 상단의 얕은 그림자와 연속된 밝은 마감이 보이고 떠 있는 판, 점검구, 댐퍼, 노출 레일·호차, 분해 구조는 식별되지 않음. 밝은 면은 개구부 위 벽/인방처럼 읽힐 수도 있어 실제 천장 매립 단면으로는 판정 불가.
- 일부 열린 상태와 손잡이는 이동식 문짝 단서. 오른쪽 주행 거리, 닫힐 때 개구부를 완전히 덮는지, 숨은 레일의 위치·점검·반출 조건은 입증 불가. 기계적 작동 및 교체 불가 판정 없음.
- 따뜻한 무광 면과 부드러운 빛으로 기존 실사형 이미지와 어울리나 B는 바닥과 안쪽 방이 넓게 보이는 별도 중거리 구도. A/B가 같은 현장의 실제 전후로 오독될 가능성을 배제할 수 없으므로 하드 컷 및 ‘별도 구조 예시’ 후편집 권장.
- 외관 소개용 조건부 후보. 천장 아래면을 명확히 보여주는 것이 최우선이면 다음 승인 이후 시점 조정 검토. 이번에는 재생성하지 않음. Scene 3, TTS, 영상 제작 없음.
