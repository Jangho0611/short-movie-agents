# DoorMaster 슬라이딩 도어 커버 v1 시각 QA

기준은 공통 문서 DESIGN_DoorMaster.md의 최초 레퍼런스와 COVER.md의 브랜드·크롭 규칙이다. 창작물은 사용자 승인 대기 상태다.

## 자산과 구성

- 최초 레퍼런스는 저장소의 docs/design-styles/door-master/references/door-master-cover-reference-v1.png.
- 간판은 같은 가이드 디렉터리의 assets/series-sign-v2/doormaster-series-sign-v2.png. 문 아이콘과 입체 테두리를 포함한 기존 투명 간판에 부드러운 그림자를 적용했다.
- 제품은 프로젝트 public/assets/images/scene01-before-ai-v3-candidate.png. Scene 4의 라벨·설명은 중복하지 않고 승인 구조 예시 원본을 비율 유지 확대했다. 상단의 빈 벽 부분만 웜화이트 배경과 혼합했다.
- 브랜드는 public/assets/logos/daesanlogo2.png의 심볼과 DAESAN / 대산종합건축자재 표기. 심볼의 원래 종횡비와 색을 보존했다.
- Pretendard Black, 배경 #F6F3EC, 제목 #20211F, 브러시 #FFCF51을 적용했다.
- 제목은 ‘댐퍼 교체하려다’와 ‘천장까지 뜯었다고?’ 두 줄. 더 큰 ‘천장까지’ 뒤에만 불규칙한 노란 획을 배치했다. 부제는 ‘슬라이딩 도어, 마감 전 꼭 확인할 것’.
- 제작 소스는 scripts/make-doormaster-cover-v1.py. 제품 배경, 간판, 제목·브러시, 부제, 심볼·브랜드를 분리했다.

## 출력 확인

|검사본|직접 확인한 결과|
|---|---|
|9:16 원본, 1080×1920|360×640 축소에서 간판, 두 줄 제목, 부제가 읽힌다. 강조가 해당 단어에만 걸리며 철자와 물음표를 확인했다. 레일과 양쪽 호차, 브래킷이 이어지는 문짝 상단이 보인다. 사진 가장자리에 카드나 직선 합성 경계가 보이지 않는다. 좌하단 한글 브랜드명은 작다.|
|중앙 3:4, 1080×1440|y=240부터 자른 결과 간판, 제목, 부제, 두 연결부와 구조 예시 안내가 남는다. 하단 브랜드는 제외된다.|
|중앙 4:5, 1080×1350|y=285부터 자른 결과 동일 핵심 요소가 남는다. 문 아이콘 위 여백은 3:4보다 좁다. 하단 브랜드는 제외된다.|
|최초 레퍼런스 비교, 1160×1080|간판, 비대칭 제목, 브러시, 화면 밖까지 이어지는 제품의 순서를 비교했다. 이번 편은 두 문틀 비교 대신 한 레일을 따라 양쪽 문짝 연결부가 보이는 구도다. 상단 여백은 중앙 크롭에서 간판을 살리기 위해 더 크게 잡았다.|

구조 예시는 설명용 승인 AI 이미지다. 댐퍼의 위치, 탈거 가능성, 실제 사건 현장의 상태는 사진에서 확인할 수 없다. 사용자는 원본의 상단 여백과 축소본의 간판·제목·철물 위계, 중앙 크롭에서 브랜드가 빠지는 구성을 최종 시각 승인한다.
