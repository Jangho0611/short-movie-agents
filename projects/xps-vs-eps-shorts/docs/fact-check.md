# XPS/EPS 사실 확인 — 2026-09-18

공식 제조사 자료만 제작 근거로 사용. 영상에는 물성 수치와 우열 순위를 넣지 않는다.

- EPS = 비드법 보온판: 삼정이피에스 제품 분류 https://samjeongcorp.com/20
- EPS 비드의 예비발포·성형: BASF가 제공하는 EUMEPS EPD §2.6. 비드를 수증기로 발포한 뒤 블록 성형하고 절단한다. https://fepwaf20.basf.com/portal/load/fid1232411/Expanded%20Polystyrene%20%28EPS%29%20Foam%20Insulation%20%28density%2015%20kgm%29.pdf
- XPS 압출발포와 미세 독립기포, 낮은 수분 흡수, 제품별 압축강도와 바닥/옥상 적용: 벽산 아이소핑크 제품 소개. https://byucksan.com/01_product/product.asp?cate=001002003
- XPS = 압출법 보온판이라는 명칭은 위 제조 방식 및 제조사 압출법 제품 분류에 대응한다. https://samjeongcorp.com/ (제품소개 → 압출법)

표현 제한:
- 아이소핑크는 XPS 제품 사례로만 근거 활용하며 영상에 브랜드 제품/로고/사진을 넣지 않는다.
- 제조사의 절대적인 방수 홍보 문구 대신 사용자가 지정한 '낮은 수분 흡수'만 사용.
- EPS도 비드 내부에는 독립기포가 있다. EPS를 열린 기포/물 흡수 스펀지로 그리지 않는다.
- XPS만 바닥/옥상에 쓰인다는 의미가 되지 않도록 적용 부위·물성은 제품별 확인 필요를 표시한다.
- 도형은 구조 개념도이며 실제 제품 단면/비율/색상을 재현한 이미지가 아니다.
- 어떤 소재도 모든 조건에서 우수하다고 표현하지 않는다.
