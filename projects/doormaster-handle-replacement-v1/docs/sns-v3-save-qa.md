# SNS v3 및 승인 결과물 QA

최신 사용자 제공 원문을 플랫폼별로 그대로 저장: docs/sns-upload-copy-v3.md. 추가 형식은 플랫폼 구분 제목뿐이며 본문·댓글·문구는 변경하지 않았다. 기존 SNS 파일 충돌 없음.

| 플랫폼 | QA |
|---|---|
| YouTube | 제목/설명/고정프로모원문/해시태그5개/고정댓글 확인 |
| Instagram | 본문/고정프로모원문/해시태그5개/고정댓글 확인,계정명 중복표기 없음 |
| Naver Clip | 통합본문222자,해시태그5개,별도제목/고정댓글/긴프로모 없음 |

Naver222자는 Unicode codepoint 기준으로 첫문구·공백·9개LF줄바꿈·사이트표기·모든해시태그를 포함했다. 마지막 파일 종결LF는 복사용본문 외 구분이며 제외했다(포함하면223자). UTF-16 code unit224개로 계산해도300자 이내. 문자수는 복사용SNS파일 밖 이QA에 기록했다.

YT/IG 고정프로모블록2회가 원문과 정확히 일치한다. Naver는 플랫폼별 지시대로 긴프로모를 넣지 않았다. 가이드기본 가격태그 대신 사용자가 확정한 #도무스손잡이/#손잡이교체를 유지했으며 임의수정하지 않았다. 미확인설치호환성 보장 또는 AI연출을 실제시공사진으로 단정하는 문구 없음. 재고/함께배송 문구는 사용자가 승인해 제공한 사업정보로 저장했으며 별도재고실사를 한 것은 아니다.
