## 좌표 측정과 정렬

좌표 원점은 각 1080×1920 이미지 좌상단, x 오른쪽/y 아래. 보이지 않는 실제 기계 축이 아니라 이미지에 보이는 축 칼라 외곽의 투영 중심을 추정했다.

1. Before의 금속 축 칼라에서 보이는 호의 경계11점을 확대 이미지에서 수동 추출하고 OpenCV 타원 적합. 레버 앞쪽 끝이나 원형 플레이트 외곽 중심을 축으로 사용하지 않음. 선택 점과 적합값 JSON 보존.
2. 같은 문짝 패널선 주변100×100px 기준점6개를 ±20px 범위 정규화 상관 매칭. NCC>0.8인4곳만 채택: (700,800)→(700,799), (680,1600)→(680,1600), (670,1300)→(670,1296), (690,350)→(690,348). 상관0.815~0.991. 이동 중앙값(0,-1.5)px. 질감이 약한2곳 제외.
3. 전체 공간 SIFT homography도 진단했으나 문틀/바닥 등 깊이가 다른 면이 섞이고 국소 투영이 달라 동일 문짝 정렬 기준으로 채택하지 않음. 원근이 실질적으로 바뀌었다고 가정해 전체 이미지를 워핑하지 않았다. 패널선의 생성 오차로 잔여 수 px 불확실성 존재.
4. Scene3 타공은 제한 ROI에서 회색조110 이하의 최대 개구 윤곽에 타원 적합. v1/v2 동일 방식 사용. 잘린 면 바깥 전체 치수가 아니라 어두운 개구 경계 기준.
