## 판정

| 항목 | 판정 | 관찰 및 제한 |
|---|---|---|
| 공간·문짝 구조 | 시각 PASS / 픽셀 동일 WARN | 문 패널 홈·문틀·벽·바닥·조명·구도 대체로 유지. 벽과 문 표면의 미세 질감/밝기 변화는 있음 |
| 손잡이 제거 | 시각 PASS | 기존 레버·원형 플레이트와 레버 그림자가 제거되고 해당 부위에 구멍이 표시됨 |
| 제거 위치 정합 | WARN | 같은 설치 영역이나 구멍 중심이 Before의 축 중심보다 약간 높아 보임. 정밀 정합 PASS로 확정하지 않음 |
| 타공 외관 | 일반 연출로 대체로 자연스러움 / 기술 미검증 | 사선 시점의 타원형 개구, 밝은 절단 가장자리와 어두운 내부. 실제 타공 지름·재료 단면·깊이는 확인 불가 |
| 내부 구조 | WARN / 기술 미검증 | 어두운 내부에 축 구멍처럼 보이는 부품이 일부 생성됨. Before에 보이지 않던 부분이므로 실제 래치 구조로 인정하지 않음. 기술 설명 확대 자료로 쓰지 않음 |
| 문 측면·래치 | 가시 영역의 큰 모순 없음 / 미검증 | 기존 프레임의 금속 받이와 문틈 유지, 프레임에 새 타공 추가 없음. 문짝 측면 래치 구멍과 내부 연결은 가려져 있어 정합 검증 불가. 래치까지 제거한 상태로 설명하지 않음 |
| 설치 흔적 | 시각 PASS / 실제 흔적 미검증 | 얇고 옅은 원형 접촉 흔적. 과도한 오염·녹·파손·갈라짐 없음. 실제 로즈 아래 흔적의 크기·색은 AI 추정 |
| 모바일 인지 | 시각 PASS | 360×640 축소에서 어두운 타공 식별 가능. 미세 원형 흔적/내부 구조는 작아 잘 보이지 않음 |
| 이미지 문자 | PASS | Scene 후보 내부 숫자·문자·로고·라벨 없음. QA 보드 여백에만 비교 안내 |
