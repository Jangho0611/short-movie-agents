## 승인 엔딩 확인

Slim Copy manifest로 엔딩 컴포넌트/직접 의존 소스, 본사 배경 원본/hold 영상, 로고, 승인 엔딩TTS, 실사용 폰트 등14개를 원본과 SHA256 대조 PASS. 패키지/설정은 엔딩 표현 자산 잠금 대상과 구분. 승인 엔딩 MP4 영상 패킷을 그대로 연결했으며 재설계/렌더/재인코딩하지 않았다.

최종 영상 마지막170프레임을 순차 디코딩해 Canonical170프레임과 비교: **전 프레임 RGB 픽셀 해시 동일**. 엔딩 오디오는 Canonical AAC를 PCM으로 디코딩하여 정확한 프레임 길이에 맞는 끝 여유만 채우고 전체 AAC 믹스로 인코딩했다. TTS 재생성이 아니며, 압축 비트스트림 동일성은 주장하지 않는다.
