# Scene4·5 TTS 호흡 수정 QA

2026-10-22 / 후보 각1개, 사용자 청취 승인 대기. 자연스러움 PASS 아님.

## 기준과 방식

최신 공통 지침의 자연스러운 발화/부분 수정 및 운영가이드 §9·10 적용. 대본·Alnilam 음색·기존 rate1.00 보존, pitch 변경 없음. TTS API 재합성0회. 기존 발화를 보존하는 국소 무음 삽입 후처리를 우선 적용했다. 억양 자체를 고친 것은 아니며 기존 억양이 자연스럽다고 자동 판정하지 않는다.

원본 파형을 직접 확인하고 -38dB/최소0.025초 저레벨 구간을 검출했다. 이전 -30dB/0.1초 검사와 기준이 달라 수치는 직접 비교하지 않는다. 로컬 Whisper base 자동 전사/DTW를 보조적으로 사용했다. 단어 오인식과 부정확한 타임스탬프가 있어 정답 또는 발음 QA로 사용하지 않고, 의미 구절의 대략적 위치와 실제 파형을 대조했다. 특히 Scene5 짧은 경계의 실제 단어 위치는 사용자 청취 재확인 필요.

| 대상 | 확인하세요 → 그리고 예전 | 조건만 맞는다면 → 문짝 |
| 원음 저레벨 경계 | 3.204250–3.759208초 | 1.632750–1.658750초 |

이 표의 종료/시작은 임계값 기반 활동 경계로, 청각적으로 확정한 음절 종료/시작이 아니다. Scene4는 기존 약0.555초 문장 쉼을 약0.735초로 조금 늘리고, Scene5는 거의 없는 조건절 쉼을 약0.246초로 확보하는 후보를 선택했다. 다른 쉼표나 Scene 사이에는 무음을 추가하지 않았다. Scene4 기존0.555초가 객관적으로 짧다는 뜻이 아니라 사용자 지적에 대한 최소 수정 후보이다.

24kHz PCM의 저진폭 위치를 골라 0값 샘플만 삽입했다. 접합 주변 원음 값은 Scene4[-1,0], Scene5[0,-3](16bit PCM)로 이음 급변이 작다. 음절 삭제/페이드/타임스트레칭/속도·피치·볼륨 조정 없음. 삽입 구간을 제거하면 인코딩 전 PCM이 원본 디코딩 PCM과 바이트 단위로 동일함을 검증했다. MP3 재인코딩이므로 출력 파일의 파형은 손실 압축에 따른 미세 차이가 있으며 bit-identical 음질 보존을 주장하지 않는다.

## QA 판정

- 기술 PASS: 선택5개와 통합 파일 전체 디코딩 성공, 포화 샘플0, 기존60개 src/public 파일 SHA256 동일. Scene1·2·3 및 원본 Scene4v2/Scene5v1/통합v2 보존.
- 발화 보존 PASS(편집 구조): 원본 PCM 샘플을 삭제하거나 늘이지 않았음. 끝소리 샘플 보존. 원음 자체에 잘림이 있었는지는 청취 미검증.
- 클릭·팝: 접합점이 거의0이고 파형 단절을 최소화함. 기술적으로 큰 계단형 접합 없음. 실제 가청 클릭/팝 여부는 청취 미검증.
- 자연스러움/억양/음색/필러/과도한 정적/전체 리듬: 사용자 청취 대기, PASS 부여하지 않음. 억양은 그대로이므로 원래 시작 억양이 부자연스럽다면 이번 수정으로 해결되지 않는다.
- Scene4→5 연결: Scene 사이 새 쉼 없음. 통합본 저레벨 경계20.168–21.061초(약0.893초)는 원음 끝·시작 여유의 합과 인코딩 영향. 늘어지는지 직접 확인 필요.

| 출력 | LUFS | True peak dBTP | Sample peak dBFS |
|---|---:|---:|---:|
| scene04-tts-v3.mp3 | -20.2 | -2.3 | -2.31 |
| scene05-tts-v2.mp3 | -21.3 | -3.0 | -3.05 |
| full-tts-qa-v3.mp3 | -20.5 | -0.9 | -0.88 |

LUFS/peak 변동은 무음 추가와 손실 재인코딩을 포함하며 수동 음량 조정은 하지 않았다. 개별 원음값·무음 목록은 `docs/tts-breath-mechanical-v3.json`에 보존.
