# Preview v2 QA — Scene 4 단순화

## 변경 범위
최신 로컬 통합 지침 및 기존 Preview v1 작업기록을 기준으로 Scene 4만 새 컴포넌트 `src/scene04-simple-v3.tsx`에 구성했다. 기존 소스는 보존했다. 승인 `DoorMasterBodyCaptionV4`를 그대로 import하여 폰트·크기·색·외곽선·중앙 위치·5프레임 등장 모션을 유지했다. Scene 1·2·3·5 및 엔딩은 기존 영상 패킷 재사용. 전체 오디오는 Preview v1 AAC 스트림을 무재인코딩 복사했다.

A는 기존처럼 최초 0.4초에 자막 등장, 0.567초부터 완전 표시된다. B/C는 전환 후 5프레임 등장이다. 표의 유지시간은 전환 포함이며 A 완전 표시 약1.433초, B 약1.833초, C 약3.333초다. 7.488초 승인 음원과 225프레임을 유지해 별도 추가 Hold 없이 끝의 프레임 정렬 여유만 남겼다. C는 문장 전체에 걸쳐 3.5초 유지하므로 추가 정지는 적용하지 않았다. 최소 읽기시간 충족의 최종 판단은 사용자 시청 대기.

기존 네 화면(0/1.2/2.167/4초)을 세 화면(0/2/4초)으로 통합했다. 기존 타공·문두께, 그리고 래치 확인, 하지만 교체 후 자국의 의미 경계에 맞췄다. 기존 분석상 문장 경계 무음 3.513–4.008초를 참고해 C를 4초에 시작했다. 파형/분석 기반 정렬이며 직접 청취로 정확한 강조 싱크를 확정하지 않았다.

## 화면 QA
- 360×640 모바일 축소 대표 프레임에서 2줄 제목 잘림·겹침 없음. 승인 검정 기본색/노란 강조 유지.
- A/C는 승인 Scene 3 v2 전체 구도 이미지를 그대로 활용하고 원형 그래픽만 겹쳤다. 이미지 타공/표면 자체는 변경하지 않았다.
- B는 기존 제조사 설치도면의 동일 영역을 확대했다. 백셋60mm 및 문짝 끝단↔손잡이 중심 설명 유지. 도면 원본의 Ø54/Ø25 표기는 원본 보존상 남아 있으며 Ø54/Ø55 비교 설명은 제거했다.
- 35~45mm는 ‘511 NI 적용 문두께’로 의미를 명확히 하고 실제 문은 실측하도록 표시했다.
- 작은 출처·호환성 비교 강조·내부 검증 메모·중복 설명 제거. 자국은 ‘보일 수 있어요’로 가능성만 전달한다.
- 실제 도면과 수치는 변경하지 않았다. 공식 Ø54mm/대산 등록 Ø55mm 차이는 미해결이며 설치 호환성 미확인 상태 유지. 역사적 기술기록도 보존.
- 정지 대표 프레임 시각 검토 완료. 연속 재생의 가독성·Scene 3→4/4→5 체감 연결·청취 자연스러움은 사용자 확인 대기. 자동 검사로 해당 항목 PASS를 부여하지 않는다.
