# Scene 4 화면 설계 v1

상태: 문서 설계만 완료 / 사용자 승인 대기. 이미지·영상·Remotion 구현·TTS 생성 없음.

## 고정 기준

- TTS v3 원문: “기존 타공과 문두께, 래치 규격을 확인하고, 예전 손잡이 자국이 가려지는지도 살펴보세요.”
- Scene 순서와 공통 엔딩 유지. 발화 시간 미확정이므로 초/프레임을 미리 고정하지 않는다. 아래 네 구간은 발화 의미 단위로 연결하며 승인 음성이 생긴 뒤 길이를 맞춘다.
- Before v1 승인. After v1은 시각 구성만 조건부 승인, 511NI 세부 형상 최종 검증 아님. Scene 3도 별도 승인 전 사용 확정하지 않는다.
- 숫자는 기존 문의 실측값이 아니라 511NI 공식 자료의 제품/가공 조건임을 분리한다. 실제 호환성 PASS 표시 금지.

## 화면 구성 및 Scene 3 연결

1080×1920 세로. Scene 3 마지막 화면과 같은 이미지·위치로 시작해 연속성을 유지한다. 상단은 짧은 핵심 자막, 중앙은 타공 부위 또는 공식 자료, 하단은 해당 항목의 확인 문구를 배치한다. 웜화이트·블랙·노랑의 문도사 톤을 사용하며 손잡이 구멍을 가리지 않는다. 4개 정보를 작은 카드로 동시에 나열하지 않고 순차 강조한다. 자막은 최대 2줄, 실제 모바일 크기로 추후 QA한다.

| 발화 구간 | 화면 및 핵심 자막 초안 | Remotion 처리 |
|---|---|---|
| “기존 타공과” | 승인된 Scene 3의 구멍 위치를 가볍게 강조. 자막: `기존 타공 / 크기·위치 확인` | 비수치 원형 가이드와 중심 표식. 필요하면 동일 이미지의 타공 부분만 인셋 확대. AI 구멍에 Ø54/55 실측선을 직접 붙이지 않음 |
| “문두께,” | 공식 511NI 적용 문두께 텍스트 `제품 적용 문두께 35~45mm`와 `기존 문은 실측` 구분. 문두께를 재는 실제 측면 사진이 확보되면 함께 제시 | 단순 측정 개념 2D 선도와 양방향 화살표. `측정 위치 예시·축척 없음` 표기. ABS 내부 단면/심재/보강재를 그리지 않음 |
| “래치 규격을 확인하고,” | 511NI 공식 설치설명서 1번 부분을 읽을 수 있게 크롭해 문 끝에서 축 중심까지 확인. 자막: `백셋·래치 / 함께 확인` | 원문 위 60mm 백셋 위치 강조선. 기존 문의 백셋은 별도 `실측 필요`. 필요할 때만 공식 측면 타공 Ø25mm 보조 표기. 54/55 차이 설명과 혼잡해지면 Ø25는 화면에서 생략하고 근거 문서에 유지 |
| “예전 손잡이 자국이 가려지는지도 살펴보세요.” | Scene 3 타공 주변으로 복귀. 자막: `새 플레이트 밖으로 / 자국이 남을 수도` | 공식 65×65mm 사각 플레이트 도면을 별도 자료로 제시. 기존 원형 흔적/새 사각판의 비축척 2D 개념도를 사용해 노출 가능성만 설명. AI 이미지 위 정확한 가림 시뮬레이션처럼 합성하지 않음 |

Scene 3의 생성된 구멍은 질문을 제기하는 시각 자료로만 사용한다. 정확한 수치 설명은 공식 자료 영역으로 전환한다. Scene 4에서 손잡이 설치 성공/완료 모션을 추가하지 않고, 기존 순서대로 Scene 5의 조건부 결론으로 연결한다.

## 공식 확인값과 미확인값

근거: docs/product-reference-report.md 및 그 문서의 제조사 511NI 상세 페이지에 직접 연결된 자료. 공식 도면과 공식 설치설명서의 역할을 혼동하지 않는다.

| 항목 | 확인된 근거 | 미확인 또는 제한 |
|---|---|---|
| 플레이트 | 공식 외형 도면: 65×65mm, 두께7mm, 둥근 모서리 사각 | 기존 원형 자국 실제 지름·깊이·색 변화, 가림 가능 면적 |
| 레버 | 공식 외형 도면: 길이125mm, 돌출42mm | After 생성물의 정확한 재현 여부. Scene 4 치수 설명에 After를 도면 대신 사용 금지 |
| 문두께 | 공식 제품 본문: 35~45mm | 기존 문의 실측 두께, 내부 보강 상태 |
| 전면 타공 | 모델 페이지 연결 설치설명서: Ø54mm | 사용자 제시 대산 등록 Ø55mm와 차이 미해결. 대산 원문/제조사 확인 없이 허용오차나 상호 호환으로 해석 금지 |
| 백셋 | 모델 페이지 연결 설명서: 문 끝~축 중심60mm | 기존 문 실제 백셋, 조절 가능 범위·다른 백셋 호환 |
| 측면 타공 | 모델 페이지 연결 설명서: Ø25mm | 이를 래치 몸통 직경으로 단정 금지 |
| 래치 | 설명서상 방향 전환 래치볼트 조립 관계 | 몸통 길이/폭, 전면판 치수, 체결 간격, 스핀들/나사 호환, 기존 받이쇠와 맞물림 |

타공 수치를 화면에 제시하는 경우 `제조사 설명서 Ø54mm / 대산 등록 Ø55mm: 차이 확인 필요`를 읽을 수 있게 병기한다. 해당 고지는 TTS 추가나 수정 없이 화면 자료로만 제안한다. 정보량이 과도하면 숫자 두 개를 모두 빼고 `타공 규격은 제품 자료·실물 대조`로 표현한다. 어느 경우에도 해결된 값처럼 하나를 선택하지 않는다.

추가 확보/검증 필요:
1. 실제 기존 문 손잡이 탈거 사진: 정면 및 문 측면, 자/캘리퍼를 함께 촬영한 타공 지름·위치·문두께·백셋.
2. 기존 래치와 새 511NI 래치의 실물/공식 상세 도면: 전면판·몸통·나사 간격·축 연결·받이쇠 위치.
3. 대산 Ø55mm 등록 자료 원문과 적용 모델/자료 시점. 제조사 Ø54 설명서와 의미/허용 범위가 같은지 제조사 확인.
4. 원형 설치 자국 실측과 65×65mm 새 플레이트 실물 외곽을 대조한 사진. 숨겨진 흔적을 AI로 추정해 완전 가림을 보장하지 않음.
