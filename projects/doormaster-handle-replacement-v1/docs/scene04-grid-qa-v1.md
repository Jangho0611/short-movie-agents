## 시각 QA
360×640 모바일 축소 대표 프레임3개 직접 확인. 네 제목,35~45mm,60mm와 타공/설치 자국 식별 가능. 겹침·잘림 없음. 최초 자국 강조선이 사진 아래에서 잘린 문제를 사진 표시 범위 확대로 수정했다(원본 무변경).
공식 도면의 작은 원문 수치/부품 인쇄는 모바일에서 세부 독해가 어려움(WARN). 백셋60mm는 도면 밖 큰 글씨로 전달하며 작은 글씨를 읽어야만 의미가 전달되도록 만들지 않았다. 더 큰 도면이 필요하면 전체 구성은 유지한 채 ③ 보조 여백 축소/도면 영역 확대가 개선 후보이며 이번에는 추가 정보를 넣지 않았다.
제목 아래 노란 밑줄만 이동하며 원형 자국의 점선은 위치 안내로 계속 유지한다. Scene3→4는 승인 이미지를 활용하지만 전체 사진에서 정보 배치로 컷 전환된다. Scene4→5는 기존 컷과 시각/음성 시작점을 유지한다. 연속 영상 실제 청취·시청의 체감 흐름은 미검증이며 정지 프레임 QA와 구분한다.
