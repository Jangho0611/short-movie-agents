## 기술 QA

선택 Scene5개/통합 MP3 전체 디코딩 성공, 포화 샘플0. Scene4 -20.3LUFS / sample peak -4.35dBFS / true peak -4.4dBTP. 통합 -20.3LUFS / true peak -0.9dBTP.

Scene4 -38dB/최소0.025초 저레벨 검사: 앞0–0.422917초, 문장 사이로 추정되는3.301417–4.174167초(**0.872750초**), 뒤7.512542–7.728초. 나머지 내부 구간은 약0.028~0.044초로 자음 등 발화 특성일 수 있다. 검출값은 청각적 경계 및 자연스러움 판정이 아니다.

Scene4는 중간 절단/접합 없는 단일 생성물. 클리핑·디코딩 검사는 PASS이나 가청 클릭·팝/발음 누락/혀짧은 느낌은 자동검사로 보장하지 않으며 청취 미검증.

## 집중 청취 — PASS 미부여

실제 청각 평가는 수행하지 못했다. 아래 항목을 사용자 직접 청취로 확인해야 한다.

- 기존 타공과 문두께 발음 및 빠른 이어 읽기.
- 그리고 래치 규격을의 연결 억양.
- 확인하세요 문장 종료감과 약0.873초의 쉼이 과도하지 않은지.
- 교체 후 기존 손잡이 자국이 시작 억양.
- 드러나지 않는지도 살펴보세요 연결과 마무리.
- Scene4→5 전체 속도·음색·호흡 일관성.

통합 Scene4 구간13.176–20.904초, 문장 경계 후보16.477–17.350초. Scene5는20.904초부터 시작. 위 초는 원음 길이/저레벨 측정 기반 안내이며 단어 정렬 확정값 아님. 문장부호와 무음값만으로 자연스러움 PASS 처리하지 않는다. 추가 생성 없이 사용자 판단을 기다린다.
