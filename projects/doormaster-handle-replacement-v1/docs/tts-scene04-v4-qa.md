## 호흡 및 기술 QA

- -38dB/최소0.025초 저레벨 검사: 앞0–0.451초, 내부3.572–4.184792초(0.612792초), 뒤6.856–7.056초. 문장 사이로 추정되는 내부 구간이며 청각적 단어 경계로 확정한 값은 아니다.

- Scene4 발화 활동 범위 추정0.451–6.856초. 실제 단어 정렬/청각 평가는 수행하지 않았다.
- Scene4: -20.5LUFS, sample peak -2.81dBFS, true peak -2.8dBTP, 포화 샘플0.
- 통합: -20.6LUFS, sample peak -0.88dBFS, true peak -0.9dBTP, 포화 샘플0.
- 선택 Scene5개 및 통합 MP3 전체 디코딩 성공. 통합은 원음 전체 PCM 연결 후192kbps MP3 인코딩. Scene 사이 무음 추가0, 트림0. 통합본은 QA 전용.
- 클릭·팝: Scene4는 중간 절단/접합이 없는 단일 생성물이다. 디코딩·클리핑 검사로 가청 클릭/팝 부재를 보장할 수 없으므로 청취 미검증으로 남긴다.

## 사용자 청취 확인 필요
