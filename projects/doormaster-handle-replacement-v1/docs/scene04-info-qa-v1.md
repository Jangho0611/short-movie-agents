## 화면 및 임시 타이밍

1080×1920, 30fps, 480프레임, 16초. 실제 발화 길이에 따른 타이밍이 아니다.

| 구간 | 프레임 | 강조 사항 |
|---|---|---|
| 0–4초 | 0–119 | Scene 3 전체 이미지에서 시작. 기존 타공 크기·위치 및 Ø54/Ø55 미해결 안내 |
| 4–8초 | 120–239 | 적용 문두께 35~45mm 및 실제 문 두께 측정 개념 |
| 8–12초 | 240–359 | 백셋 60mm, 공식 도해, 기존 백셋·래치 대조 |
| 12–16초 | 360–479 | 원형 설치 자국과 새 플레이트의 은폐 가능성 확인 |

첫 구간은 12–24프레임에 정보가 나타나며 다른 구간은 시작 후 8프레임 동안 나타난다. 한 구간에 하나의 확인사항을 강조한다. TTS 원문은 변경·생성하지 않았으며 화면에 문장 전체를 반복하지 않는다.

## 승인 TTS 생성 후 필요한 조정

TTS 싱크는 미검증. 승인 TTS v3 생성 후 네 의미 구간의 실제 발화 시작·종료에 맞춰 구간 길이, 강조 등장 시점, 도면 체류 시간 및 Scene 3→4 연결을 조정해야 한다. 현재 16초를 최종 길이로 확정하지 않는다. 실물 문의 타공·두께·백셋·래치·설치 자국 은폐 여부와 Ø54/Ø55 차이는 별도 확인이 필요하다.

Scene 5, 전체 Preview/Final, TTS, Cover, SNS는 제작하지 않았다. 기존 승인 자산 수정, 파일 삭제·이동, Git commit/push 없음. 사용자 승인 전 다음 단계로 진행하지 않는다.
