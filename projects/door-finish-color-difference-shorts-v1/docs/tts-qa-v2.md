## 직접 청취가 필요한 항목

실제 청취는 수행하지 못함. 질문형Hook, 문틀과 문짝·인테리어 필름·데코·인필·엠보스·열압착·결감·이질감 발음, 문장 끝 억양, Scene간 의미/호흡 연결, 속도 자연스러움, 엔딩 진입감은 미확인. PASS로 표시하지 않는다.
우선 Scene3의1.448~2.129초 쉼(통합13.760~14.441초), Scene1→2와4→5 경계, 엔딩 전환을 청취한다. 특정 단어가 오발음되었다고 판정하거나 문구를 교정하지 않았다.

## v1 대비 변화와 남은 문제

- 문장 구성상 Hook에 문틀/문짝을 명시하고, 마감종류→가공/반사원리→대안/제한→발주행동으로 연결되어 음성 자체의 설명 맥락이 늘었다. 이는 대본 분석이며 청취 자연스러움 평가가 아니다.
- 본편음성19.152→41.832초, +22.680초. 충분한 설명을 위해 기존 짧은 가배치를 해제해야 한다.
- 사용자의 확정 문구는 변경하지 않았다. 다만 Scene2의 ‘문틀은 보통’은 영림 모든 문틀의 공식 기본 사양으로 일반화하지 않도록 기존 화면 한정이 필요하다. Scene3의 열압착/결감 원리는 타사 문헌으로 설명되는 일반 원리이며 영림 전 제품의 공정/해당 현장 원인을 확정하는 표현으로 사용하지 않는다. 기존 기획서의 근거 한정 유지.
- 내레이션만으로 실제 현장의 원인이 확인된 것처럼 들리는지, 쉼이 어절 내부에서 부자연스러운지는 사용자 청취 판단이 남음. 현재 자동 수정/재합성/트림 없음.
