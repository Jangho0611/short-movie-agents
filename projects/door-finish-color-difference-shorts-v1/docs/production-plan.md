## 메시지와 사실 범위

같은 색상 번호라도 문틀·문짝의 표면 마감은 다를 수 있다. 실제 마감 샘플을 비교하고 모델·마감·전체 색상 코드를 발주서에 남긴다.

- 공식: 영림 FAQ는 인테리어필름을 점착 처리된 시공용 마감재, 데코시트를 열과 접착제로 도어·문틀·몰딩에 래핑하는 표면재로 설명한다. 모든 문틀을 인필 기본 사양으로 일반화하지 않는다.
- 공식: 2026–27 카탈로그 인쇄 140–141쪽의 YA-07E는 PVC 시트 표면재의 ABS 민자 도어. 영림190 운영, 성형 도어 적용 불가. 인테리어필름과 일체감 있는 마감 취지를 안내한다. 상세 수치·색상 목록은 본편에서 제외한다.
- 담당자 설명: 사용자가 전달한 영림 담당자 설명은 문짝 인필을 이색 최소화 방안으로 제시한다. 카카오톡 원문 직접 확인 전이다.
- 일반 원리: LX하우시스 공개 실용신안 KR20220000374U는 열/압력 가공 중 엠보 깊이 감소·광택 증가 가능성을 설명한다. 영림 공정 입증 자료가 아니다. 색소 변색, 모든 데코의 동일 변화, 특정 현장의 원인 확정으로 사용하지 않는다.
- 미확인: 별도 문틀 엠보스 발주 옵션, 인필 공식 옵션명/모델별 조건, 필름전용 범례, 동일 표면재 여부, 비용·납기 수치·색차 허용 기준.
- 이번 편 제외: 필름 로트와 추가 발주, 폼 작업 후 문 끼임, 문틀 엠보스 조합 추천.

## Scene 1 — Hook (가배치 0~3초)

목적: 첫 1~2초 안에 실제 대조 상황과 질문을 제시.
화면: 대산 비교 사진 원본 확보 후 한 프레임에 표면 두 개가 보이게 배치. 현재 게시본은 UI 포함 저해상도라 최종 원본으로 확정하지 않음. 문틀·문짝 식별이 안 되는 사진에 임의 라벨 금지.
TTS 후보: **같은 색인데, 왜 다르죠?**
자막 순서: ① 0~1.4초 `둘 다 영림190인데?` → ② 1.4~3초 `문틀과 문짝이 / 달라 보인다?`
주의: 영림190 식별은 사례 본문 근거이며 사진 속 양쪽 시료 코드가 직접 검증된 것은 아님. 원본/납품 정보 확인 후 확정. 미확인 상태에서는 `같은 번호로 주문했는데?`로 대체하는 안을 검토.
필요 자산: 대산 비교 원본, 간판 v2. 방식: 실제 사진+Remotion 표시. 승인 상태: 화면 설계 검토 대기.

## Scene 2 — 마감 방식의 차이 (가배치 3~8초)

목적: 색상 코드와 마감 사양이 별개임을 전달.
화면: 좌측 문틀 사진, 우측 문짝 사진. 본문 사진이 둘을 식별하지 못하면 원본 확보 전 임의 합성하지 않는다. 문틀/문짝 항목을 순차 강조하고 전체 카드를 동시에 읽게 하지 않음.
TTS 후보: **문틀과 문짝은 마감 방식이 다를 수 있습니다.**
자막 순서: ① `이 사례의 문틀 / 인테리어필름 마감` → ② `문짝은 사양 확인 / 인필 · 데코 · 엠보스` → ③ `같은 색상 번호 ≠ 같은 표면 마감`
화면의 작은 근거 표시: `대산 해당 사례 기준`. 설명 보조: 필름의 무늬·결감이 표면에 표현됨. 모든 영림 문틀의 기본 사양으로 확대하지 않음.
필요 자산: 문틀 표면 및 라벨, 실제 문짝. 방식: 사진+정보 카드. 승인 상태: 사진 식별 대기.

## Scene 3 — 데코시트의 질감 차이 (가배치 8~18초)

목적: 표면의 결감과 반사가 외관에 미치는 영향 설명. 필름 색소 자체가 변한다는 설명 금지.
TTS 사용자 후보: **데코시트는 열압착 과정에서 표면 결감이 약해져, 같은 색상도 다르게 보일 수 있습니다.**
TTS 검토 권고안: **열과 압력으로 표면 결감이 약해지면, 같은 색도 다르게 보일 수 있습니다.**
권고 이유: 원문의 첫 절은 모든 데코 공정에서 결감 감소가 발생한다는 인상을 줄 수 있음. 실제 TTS 제작 전 두 후보 중 확정 필요. 사용자 문구를 삭제하거나 확정 승인으로 바꾸지 않음.

화면: 실제 마감 샘플을 계속 보여주고, 하단 정보만 4단계 교체. 자료로 확인하지 못한 영림 공장 장면·기계·단면은 만들지 않음. 가짜 전후 질감 이미지도 만들지 않음.
자막 순서(각 약2.5초, 가안):
1. `열·압력을 사용하는 / 가공 과정에서는`
2. `입체적인 결감이 / 약해질 수 있습니다`
3. `표면이 매끈해지면 / 반사·광택도 달라질 수 있습니다`
4. `같은 색상 번호라도 / 다르게 보일 수 있습니다`

네 단계 동안 한정 표시 유지: `가공에 따른 일반 원리 / 영림 전 제품의 공통 사양 아님`.
근거: LX하우시스 공개 실용신안. 영림 FAQ의 ‘열과 접착제’와 구분. 본편에서 ‘영림 공식 열압착 공정’이라고 명명하지 않음.
현재 대산 사진으로 공정 전후를 입증할 수 없음. 사진은 실제 대조 사례, 정보는 일반 설명으로 분리한다.
필요 자산: 라벨 확인된 실제 데코/필름 샘플 쌍. 방식: 정지 비교+순차 정보. 승인 상태: 근거 범위 명시 완료, TTS 최종안/샘플 대기.

## Scene 4 — 인필과 엠보스 선택 (가배치 18~26초)

목적: 외관 일치 요구에 맞춰 두 대안을 상담하도록 안내.
TTS 후보: **문틀과 최대한 맞추고 싶다면 인필이나 엠보스 도어를 검토해 보세요.**
화면: 같은 문틀 기준 샘플을 유지하고 인필/YA-07E 후보를 순차 제시. 우승 배지·100% 일치·가격 순위 없음. 비교 샘플 미확보 시 공식 제품 소개와 상담 안내로 한정.
자막 순서:
1. `인필: 인테리어필름 마감 / 마감재 차이를 줄이는 대안` (약2.5초)
2. `엠보스: 입체 질감을 살린 문짝 / YA-07E 적용 사양 확인` (약2.5초)
3. `실제 샘플을 비교하고 / 추가 비용·납기도 확인` (약3초)

엠보스의 상세 규격·색상 목록은 본편에 넣지 않음. 문틀 엠보스 옵션은 미확인으로 본편 제외.
필요 자산: 인필 샘플, YA-07E 공식 이미지/실물, 문틀 기준 샘플. 승인 상태: 원본·제품별 사용권/샘플 확인 대기.

## Scene 5 — 발주 전 확인 (가배치 26~32초)
