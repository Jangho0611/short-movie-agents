## QA

- 로컬 공통 SNS 가이드 v1.6 확인. 이번 지시의 통합 본문 300자·태그 최대 5개 기준 적용.
- YouTube: 제목·본문·고정 프로모·해시태그·질문형 고정댓글 순서 확인.
- Instagram: 본문·고정 프로모·해시태그·질문형 고정댓글 순서 확인. #릴스·#reels 및 계정명 미추가.
- 플랫폼별 해시태그: 각각 5개. 도어 → 건축자재 → 대량구매 → 도어가격 → ABS도어 순서 일치.
- YouTube·Instagram 고정 프로모: 로컬 가이드 코드 블록 원문과 각각 완전 일치. 위아래 구분선·빈 줄 유지.
- daesan.ai: YouTube·Instagram은 프로모에만, Naver는 짧은 구매·납품 안내에 포함.
- Naver Clip 실제 글자 수: **246자 / 300자**. 첫 문구·공백·모든 LF 줄바꿈·해시태그 포함. 코드 블록 구분자와 본문 끝의 포맷용 줄바꿈은 제외. 본문 내부 줄바꿈 9개. Python len 기준 Unicode 코드 포인트 수. UTF-16 기준 247단위로 계산해도 300 이내.
- Naver는 별도 제목·고정댓글·긴 프로모 없음.
- 실측·가공·호환성 확인 필요라는 승인 메시지 유지. 특정 YA-990·511 NI 조합의 호환성, 실제 가공치수, 가격을 확정하지 않음.
- 대산의 직접 시공 제공·시공 전문업체 표현 없음. 건축자재 구매·유통·납품 상담으로 한정.

### 초안 대비 수정

1. 전 플랫폼 최대 5개 규칙에 맞춰 YouTube 제목의 #Shorts 삭제. 본문 기본 해시태그 5개 유지.
2. YouTube·Instagram의 키홈 표현에 “래치가 들어가는 받이 위치”를 덧붙여 열쇠 구멍과의 혼동 완화.
3. YouTube·Instagram에 가격·구매 조건·대량구매·납품 상담 시 확인할 정보를 짧게 추가. 가격 수치·시공 서비스는 추가하지 않음.
4. Naver 초안을 핵심 확인 항목·주의점·구매 안내·태그를 유지하며 300자 이내로 간결하게 정리.
5. 고정 프로모 안내용 자리표시자를 실제 가이드 원문으로 치환. YouTube·Instagram은 본문부터 태그까지 한 번에 복사 가능한 블록으로 구성.
