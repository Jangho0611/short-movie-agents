# 씬2 문선 제거 개념 비교 v1 QA

원본 도해 기반 개념 비교로 제작 승인됨. 실제 제품 분리 구조를 확정한 시공도가 아니다. 기준 common-section-v4.svg, 출력 A/B 각 1080×1920.

## 변경

- A: 기존 넓은 문선 표시, B: 동일 existing-casing 그룹만 display=none.
- 제거 대상을 구별하기 위해 기존 문선 색상만 기존 포인트 #FFE600으로 설정. 문선 도형 x179,y433,width88,height18은 유지.
- 상단 자막 A '기존 넓은 / 문선', B '문선만 / 제거!'. v4의 배경·차콜/노랑·폰트·크기·구도 유지.
- 받침 보강 영역과 MDF는 A/B 모두 display=none. MDF는 빈 그룹. 원형 확대 없음.

## QA PASS

1. 문짝·기존 문틀·벽체·부품명 그룹 A/B XML 비교 동일. 문짝 간격 및 전체 transform도 v4와 동일.
2. 받침 보강 영역과 MDF는 두 이미지 모두 숨김.
3. 기존 문틀 외곽과 하단 곡면 유지. 제거 후 손상·절단선 없음.
4. 제목을 제외한 y600 이하 전체 화면의 픽셀 차이 범위: (476, 1201, 736, 1266). 문선과 해당 그림자 영역에만 변화가 있으며 다른 단면 부분은 동일.
5. 제거 후 배경이 자연스럽게 드러남. 문틀/벽체를 지우거나 변형하지 않음.
6. 신규 홈·피스·접착층·절단선·받침 실형상·MDF 도형 없음.
7. 씬3에서 동일 support-zone의 표시 상태를 바꿀 수 있는 레이어 구조 유지. 실제 받침 형상은 미확정.
8. PNG 직접 시각 검수: 제목 잘림·단면 가림 없음, A의 노란 문선과 B의 제거 상태 명확.
