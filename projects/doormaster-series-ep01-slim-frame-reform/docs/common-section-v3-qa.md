# 공통 단면 디자인 v3 QA

2026-10-13 / 정지 디자인 시안 1장 / 사용자 승인 대기.

## 기준

기존 PROJECT_HANDOFF.md, docs/daesan_shorts_instructions.md, docs/design-styles/README.md, docs/26.09.11_테스트레퍼런스.md 및 승인 현장형 v7의 초굵은 한글·2줄·핵심어 노랑 기준을 유지한다. 최신 사용자 지시에 따라 밝은 배경과 차콜 본문을 적용한다. 색상은 이번 영상의 디자인 선택이며 새 대산 공통 표준을 제정하지 않는다. 이전 common-section-v2-design-qa.md의 기준 경로와 출처 구분도 유효하다.

## 변경 및 검증

- 배경 #F7F5F0 웜화이트. 검정 전체 배경과 카드 없음.
- 제목: Apple SD Gothic Neo/Noto Sans KR 계열, 굵기 900 유지. 96/112px에서 78/94px로 축소. 차콜 #303431 본문, 기존 #FFE600 핵심어에 #343735 4px 외곽선 적용.
- 단면 전체 배율 2.5→2.7, 너비 910→982.8px로 약8% 확대. 좌우 여백 약49px 유지. 원래 부품별 좌표·경로·곡면 불변, 전체 균등 확대와 위치 조정만 적용.
- 문짝 밝은 베이지, 기존 문틀 절제된 회녹색, 벽체 웜그레이로 구분. 색은 도해 식별용이며 실제 재료 사양·현장 색상 확정이 아니다.
- 얕은 그라데이션과 부드러운 그림자만 사용. 원근 변형 없음.
- 하단 여백에 동일 곡면과 보강 영역의 확대 보기를 배치. SVG use로 원본 path와 영역 rect를 직접 참조하며 새 구조를 만들지 않음. 원형 경계는 확대 창이며 카드가 아님.
- 6개 독립 레이어 유지. 문선 기본 숨김, MDF 자식 요소 0개. 외곽의 d/x/y/width/height/rx를 v2와 비교해 변경 없음 확인.
- PNG 1080×1920. 직접 시각 확인: 제목·단면 잘림 없음, 주단면과 제목 분리, 보강 위치 식별 가능. 모바일 축소 시 제목 우선 위계를 유지하도록 부품명도 굵게 조정.

받침 점선은 위치를 표시하는 보강 영역이며 실제 자재 외곽이 아니다. 확대 보기 역시 동일한 미확정 영역 표시다. MDF 돌출 방향·끝단·최종 부착 형상은 제작하지 않았다.

씬1~4 밝은 배경, 씬5 어두운 반전 검토, 씬6 밝은 복귀는 다음 단계의 방향으로만 기록. 해당 씬이나 전환을 제작하지 않았다. TTS·AI 이미지 생성·모션·영상 렌더 없음. PNG는 요청된 정지 시안의 SVG 변환이다.
