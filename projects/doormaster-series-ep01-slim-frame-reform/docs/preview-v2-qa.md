## 수정 범위

씬4 접촉 표현과 씬5 배경/강조, 전체 TTS 발음 입력·호흡 및 이에 따른 씬 길이만 수정했다. 씬1·2·3·6의 화면 함수는 기존 내용 유지. 원래 시점 0/1/2.5초의 총12개 프레임을 v1과 raw pixel 비교하여 완전 동일함을 확인했다. 음성 길이에 따라 씬 종료 시점은 달라진다.

## 씬4 MDF

독립 SVG 그룹 id=mdf 사용. 고정 문짝·기존 문틀·벽체·부품명은 v1과 같은 문자열이며 좌표/외곽/카메라 transform 유지. 보강 영역도 기존 도형 유지.

0~0.4초 보강 상태 → 약0.4~1.7초 MDF 표식이 문틀 면으로 이동 → 약1.7초 이후 밀착 상태 유지. 표식의 우측 경계는 모델 x144에서 멈춰 기존 문틀의 x144 면과 일치한다. 벽체 시작은 x206이며 표식은 벽체까지 이동하지 않는다. 곡면 부위는 기존 반투명 보강 영역과 접하는 원리만 보여준다. 별도 접착제·나사·실제 받침 부품은 만들지 않았다.

전 버전의 점선 중앙선을 제거하고 연속된 MDF 면과 약한 접촉 경계를 표시했다. 기존 벽체 하단 표시선과 완전히 같은 평면으로 끝나지 않도록 표식의 하단을 일부 연장하되, 양 끝을 마스크로 생략했다. 이는 얇은 단차를 보여주는 개념적 표현이며 실제 벽 마감 기준면·돌출 방향·끝단의 확정이 아니다. 이 부분은 현장 검증 PASS가 아니며 화면에도 미확정 사실을 표시한다. 그래픽 폭 9좌표는 실제 9mm 실측 단면을 재현했다는 의미가 아니다. 9T 자재 설정, 완성 문선 폭, 9~12mm 참고 돌출량은 별개이고 후자의 수치는 표시하지 않는다.

실제 완성 문선 형상과 현장 접촉 면적은 여전히 미검증이다. 사용자 확인 후 실제 자료에 맞춰 교체할 대상이다.
