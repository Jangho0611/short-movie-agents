# 슬림 문선 리폼 통합 프리뷰 v1

상태: 6개 씬 및 승인 엔딩 통합 완료 / 사용자 승인 대기. 1080×1920, 30fps, H.264/AAC, 1235프레임, 41.166667초.

## 적용 기준과 범위

PROJECT_HANDOFF.md, daesan_shorts_instructions.md, Shorts_제작_운영가이드.md §8~10, 기존 공통 단면 v4·씬2 A/B·디자인 QA, video-plan-v3.md 및 scene04-open-questions-v3.md를 기준으로 했다. 별도 v4/v5 전체 기획 문서는 저장되어 있지 않아 최신 대화의 최종 6씬 구성을 적용했다. 기존 기획·이미지는 보존했다.

6개 대사는 사용자 원문 그대로다. 공통 운영가이드의 최근 출발 설정 Google Cloud ko-KR-Chirp3-HD-Alnilam, speakingRate 1.00, 기본 pitch 사용. 과거 현장형 1편 Fenrir는 해당 편 승인 음성으로 구분했다. 새 음성은 아직 청취 승인본이 아니다.

## 한계와 후속 수정 필요

1. 음성 발음, MDF·9밀리 발화, 쉼 및 씬3 말끝은 full-tts-qa-v1.mp3 청취로 확인해야 한다. 기계적 음량·무음 검사가 발음 검증을 대체하지 않는다.
2. 기존 문선 실제 분리 경계·고정 방식·최종 벽 마감면, 받침 재료·형상·고정법, MDF 최종 돌출 방향·끝단·고정법·도어 간섭은 미확정이다.
3. 씬1/4/5는 완성 단면이 아닌 접촉 관계 개념도다. 현장 시공도나 치수 근거로 사용할 수 없다. 9~12mm 수치는 화면에 표시하지 않았다.
4. 씬5는 동일 구도에서 접합부 강조만 적용했다. 확대 카메라 이동은 생략해 씬2~5 구조 일관성을 유지했다.
5. 씬1의 슬림 비교도 완성 외관 실측 재현이 아니다. 실제 형상을 확인하면 해당 개념 표식만 교체해야 한다.

최종 프리뷰는 검토용이며 전체 QA 완료/최종 승인으로 간주하지 않는다.
