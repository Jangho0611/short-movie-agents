# 통합 프리뷰 v3 수정 및 QA

2026-10-13 / 사용자 승인 대기. 1080×1920,30fps,886프레임,전체29.533333초. 본편23.866667초+기존 승인 엔딩5.666667초.

## 실제 수정 대상 확인

9mm/구 미리 대사는 씬3이 아닌 씬4에 존재했다. 사용자의 '번호가 다르면 실제 대사 기준' 예외 지시에 따라 씬1·2·4만 재생성했다. 씬3·5·6은 v2 음성 파일을 그대로 사용하고 바이트 동일성을 확인했다.

Google Cloud ko-KR-Chirp3-HD-Alnilam, speakingRate1.00, 기본 pitch 유지. 새 모델·배속·감정 옵션 없음. 화면 자막·표기 대사는 변경하지 않았다.

합성용 입력만 다음처럼 조정했다.

- 씬1: 기존발포문틀 철거하지 않고 슬림 문선으로 바꿀 수 있을까요?
- 씬2: 기존문틀은 살리고 넓은문선부터 제거합니다.
- 씬4: 구미리 엠디에프를 덧대 슬림 문선 형태로 마감합니다.

씬1과 씬2의 일부 띄어쓰기를 합성용으로만 연결했다. 씬2 '살리고' 뒤 문장 부호·강제 쉼 없음. 실제 억양이 자연스러워졌다는 청취 판정은 하지 않았다.

새 합성 원본은 raw로 보존했다. 앞/뒤 무음만 각각 최소0.08초/0.12초를 남기는 방식으로 줄였다. 내부 무음은 단어 경계가 확인되지 않았으므로 자르지 않았다. -43dB/0.15초 이상 검출 기준에서 씬1·2는 해당 무음 미검출, 씬4는 1.459~1.759초의 약0.301초 무음 검출. 이 구간이 어절 사이인지 단어 내부인지 직접 청취/전사로 확인하지 못했다.

직접 청취 미수행: '기존 발포문틀' 연결, '살리고' 뒤 연결 억양, '구미리' 발음, 어절 내부 끊김, 편집 접점 자연스러움은 미검증. 기계적 무음 미검출을 자연스러움 PASS로 간주하지 않는다. 씬4의 0.301초 구간은 우선 청취 확인 대상이다.

## 씬3 보강 모션

- 기존 문선 제거 상태로 시작한다. 보강 영역은 약0.2~0.7초에 표시된다.
- 독립 SVG 그룹 support-infill을 추가했다. 약0.75~1.95초에 왼쪽 아래에서 곡면 바깥 빈 공간으로 이동하고 부드럽게 감속한다.
- 이동 완료 후 씬3 끝까지 약1.4초 유지. 씬4에는 이 완료 레이어만 추가해 연속성을 유지했다. 씬4의 기존 MDF 이동, 제목, 고정 부품, 스타일은 변경하지 않았다.
- 받침 개념 모양은 기존 곡면 외곽과 모델 x144 평면 사이의 빈 영역이다. 원래 문틀 곡선을 재사용하여 반대편 공간을 표현한 것으로 실제 재질·가공법·규격을 확정한 것이 아니다.
- 이동 경로는 왼쪽/아래에서 접근한다. 곡선 경계의 x는 y에 따라 증가하므로 왼쪽/아래로 이동한 받침이 고정 문틀 내부로 들어가지 않는다. 완료 시 모델 x144의 왼쪽 지지면은 씬4 MDF 오른쪽 x144에 맞닿는다. 받침 최대 x166은 벽체 시작 x206과 분리된다.
- 못·피스·접착제, 내부 홈, 재료 질감, 새로운 문틀 형상 없음. 원본의 문짝/문틀/벽체/곡면은 그대로다.
- 씬5·6은 별도 변경하지 않았다. 씬5는 기존 v2의 영역 강조 표현을 그대로 유지한다.
