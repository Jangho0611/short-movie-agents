# 씬4 구조 미확정 사항 — v3

2026-10-13. 이 문서는 이미지 제작 승인이 아니라 구조 확인을 위한 기록이다.

## 사용자 설정으로 유지하는 내용

- 기존 일반 발포문틀 유지 / 기존 넓은 문선 제거.
- 곡면 빈 공간의 받침은 MDF가 뜨지 않게 지지하는 역할.
- MDF 두께 설정 9T. 문틀 안쪽 면과 받침에 접촉하며 벽체 부착재로 표현하지 않는다.
- 실제 현장에 적용될 상세 형상과 공법은 아직 검증되지 않았다.

## 미확정 항목

| 항목 | 확인 필요 자료 / 미확정 시 제한 |
|---|---|
| 기존 틀 | 제조사·모델 또는 실제 단면·문선 제거 후 사진. 영림 등 타 제품 단면을 복제하지 않음 |
| 제거 범위 | 문선과 기존 틀의 분리 경계, 부분 철거 가능 여부. 문틀 전체를 없애지 않음 |
| MDF 부착면 | 문짝·스토퍼·벽 마감면을 함께 표시한 실제 사진/스케치. 화면 방향만으로 부착 방향을 확정하지 않음 |
| MDF 양 끝·재단 폭 | 실제 시작/종료 위치와 도어 간섭. 임의 길이·실제 끝처럼 보이는 생략 처리 금지 |
| 받침 | 재료, 크기, 위치, 연속/부분 설치, 형상, 고정 방법. 곡면에 맞춘 큰 가공 받침을 상상해 만들지 않음 |
| MDF 고정 | 기존 표면 처리, 접착/기계 고정 방식, 접촉 면적. 확인 전 타카·피스·접착층을 그리지 않음 |
| 최종 벽 마감 | 기존/보수 마감층과 기준면. 벽체 구조면을 곧 최종 마감면으로 간주하지 않음 |
| 돌출량 | 사용자 전달 9~12mm는 참고 범위. 톱스타 설명은 약 10~12mm. 이번 현장의 수치·방향·측정 기준면 미확정 |

9T는 판재 두께, 완성 문선 폭은 정면 노출 테두리 폭, 돌출량은 최종 벽 마감면과 문선 마감면의 관계다. 같은 값으로 처리하지 않는다.

## 기존 이미지 판정

- v1·v2는 미승인 개념 이미지다. 실제 시공 증거·정확한 제품 단면·길이/곡률/재료의 근거가 아니다.
- v1: 큰 둥근 덩어리 형상과 과도한 MDF 연장, 미확인 홈이 표현됐다.
- v2: 질감과 접촉 표현은 바뀌었으나 문틀·받침 형상과 재질은 실측 근거가 없다. 문짝·스토퍼·최종 벽 마감면이 없어 슬림 문선의 완성 관계를 검증할 수 없다.
- 생략선으로 길이를 감추는 것만으로 미확정 구조 문제가 해결되지 않는다.

## 이전 조사 근거와 한계

1. LX Z:IN: https://www.lxzin.com/styling/style-guide/detail/1385

3. 금도어은도어: https://goldsilverdoor.com/door-frame/
   - 기존 틀 철거 후 새 틀 설치하는 교체 방식. 외관 비교만 참고.
