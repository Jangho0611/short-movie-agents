## 한계
레퍼런스는 레이아웃·타이포 방향에 사용했으며 제품 단면 검증 근거로 사용하지 않았다. 기존 생성 비교 이미지의 실제 제품 정확성·실측 폭·동일 현장 여부는 미검증이다. 새 숨은 구조를 생성하지 않았다는 QA와 실제 시공 검증을 구분한다. 9mm는 요청 부제이며 MDF 9T와 완성 문선 폭·돌출량의 동일성을 의미하지 않는다.
레퍼런스 대비 중앙 크롭 보존을 위해 메인 제목·사진·브랜드 배치를 조정했다. 문 아이콘은 간단한 벡터 해석이며 원본 아이콘 파일 복제가 아니다. 이번 색상과 좌표는 v1 검토 선택값으로 공통 가이드를 변경하지 않았다.
플랫폼 실제 업로드 UI 검증은 미실시.
