## 레퍼런스 비교 — PASS
실제 reference 이미지와 v2를 나란히 시각 검토. 비대칭 기울어진 블랙 간판·결합 문 아이콘·서로 다른 제목 크기·노란 브러시 강조·하단 절반 이상의 대형 문틀·우드 도어 구성 유지. 작은 정사각 사진 2장과 일반 커버 카드 템플릿 사용하지 않음.
주요 차이: 미승인 INTERIOR SOLUTION 제거, 승인 대산 심볼/DAESAN/대산종합건축자재로 교체. 일부 목재 질감·배경 그림자 생성 차이. 이전 FAIL v1 사진은 재사용하지 않음.

## 세로/모바일 — PASS 및 한계
1080×1920 PNG. 360×640 직접 시각 확인: 시리즈명, 메인 제목, 부제, 좌우 문선 라벨 인지 가능. 큰 블랙 타이포와 슬림하게 강조 유지. 작은 하단 한글 브랜드는 확대 시 정확히 확인되지만 모바일에서 매우 작음.
시리즈명 문도사의 그것이 알고싶도어, 제목 기존 문틀, 슬림하게 바꿀 수 있을까?, 부제 일반 발포문틀 → 9mm 슬림 문선 리폼을 시각 대조. 새 불필요한 설명 없음. 캐릭터 없음.

## 중앙 정사각 크롭 — FAIL(제목 전체 보존 기준)
y=420~1500에서 메인 제목 첫 줄 상단이 잘림. 시리즈 간판과 하단 브랜드도 제외됨. 슬림하게 바꿀 수 있을까?, 부제, 두 문선 라벨과 외관 비교는 유지.
최초 레퍼런스의 독립 구도를 우선하라는 사용자 지시에 따라 작은 카드형 재배열로 해결하지 않음. 정사각 독립 사용은 이 파일 그대로 권장하지 않으며, 필요 시 별도 구도 승인 필요. 세로 커버는 정상.

## 구조/제작 한계
imagegen으로 reference 기반 외관을 생성한 커버이며 실제 현장 촬영 전후 또는 검증된 시공 단면이 아님. 숨은 구조·받침·접착제·실측 치수는 생성/확정하지 않음. 실제 제품 폭 및 9T와 최종 문선 폭·돌출량의 관계는 미검증. 9mm는 요청 라벨/부제를 유지.
한글은 reference 기반 이미지에 포함된 래스터 타이포를 시각 QA한 것이며 Pretendard로 재조판했다고 주장하지 않음. 브랜드만 승인 로고와 Pretendard 후처리. 이는 v2의 레퍼런스 시각 우선 해석이며 향후 텍스트 수정 시 별도 재편집 필요.
