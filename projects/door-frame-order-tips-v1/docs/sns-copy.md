## QA

- YouTube: 제목 / 설명 본문 / 고정 프로모 / 해시태그 / 고정댓글 구분 PASS.
- Instagram: 본문 / 고정 프로모 / 해시태그 / 고정댓글 구분 PASS.
- Naver: 제목 / 설명 본문 / 해시태그 구분 PASS. 위 업로드 원문의 본문과 해시태그 사이 빈 줄(개행 2개) 유지.
- YouTube·Instagram 고정 프로모: 사용자 승인 원문 동일 PASS.
- 해시태그: 플랫폼별 5개 PASS.
- Naver 제목: 20자(공백·문장부호 포함, 설명 제한에서 제외).
- Naver 설명 본문 100자 + 줄바꿈 2자 + 해시태그 25자 = 총 127자. 200자 이내 PASS.
- 글자 수는 Unicode 문자 기준이며 Markdown 제목·구분용 빈 줄·문서 끝 개행은 업로드 원문에 포함하지 않음.
