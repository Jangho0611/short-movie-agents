# v17 STATE3 재질·프레이밍 검증

540×960 PNG 1장만 렌더. 기존 자산 변경 없음. v14 B 미렌더.

## 변경
v16 표시 객체의 메시·행렬·수평 클리핑을 유지하고 재질만 교체했다. 웜화이트 외피, 중립 회색 가공홈, 낮은 채도의 밝은 목재색 확인 영역, 기존 실버 손잡이를 구분했다. 목재색 영역은 윗면 패턴만이 아니라 기존 홈 측벽까지 이어지는 3차원 좌표 기반 재질 영역이다. 실제 목재 보강 부품이나 신규 구멍은 생성하지 않았다. 내부 배치·재료는 교육용 가상 예시다.

STATE3 카메라 방향은 유지하고 직교 scale을 2.05에서 2.3으로 변경, 화면상의 손잡이 및 홈 주변 범위를 기준으로 프레이밍을 재중심화했다. 원본 v14 카메라와 모델은 변경하지 않았다.

## 기하 QA
원본 및 표시용 모든 메시 정점·면과 행렬 보존. 단면 높이 유지. 신규 물체/공개창 없음, 실제 가공홈 1개. 보강 예시는 기존 고체 표면의 재질 분할이며 새로운 고체 간섭은 없다. 경계 베벨 표시용 0.001 shader tolerance는 실제 공차가 아니다. 손잡이와 홈의 기존 정렬/수용 관계 보존. 표시되는 손잡이 전체와 홈 주변 투영 범위는 화면 3.5% 안전 여백 안에 있다. 원래 긴 손잡이의 상부는 승인된 수평 단면 표시로 생략되며, 프레임 잘림과 구분한다.

## 시각 QA
외피/배경, 홈의 깊이, 목재색 영역, 금속 손잡이 구분은 v16보다 개선. 왼쪽 목재색은 상면에서 홈 측벽으로 이어져 내부 깊이 표현 개선. 오른쪽 영역은 현 시점에서 상면만 보이므로 표면 무늬로 오인할 여지가 남음. 따라서 핵심 QA7(표면 패턴 오인 방지)·QA8(양쪽 모두 내부로 식별)은 부분 충족/승인 보류이며 전체 PASS 아님. 540×960에서 네 색상군과 홈은 식별 가능하나 보강 필요 여부 메시지를 자막 없이 완전히 설명한다고 주장하지 않음.

실제 제조사의 목재 보강 구조나 균일 심재 문짝으로 오인할 위험은 남는다. 실제 타공·고정 방식·보강 배치/규격은 미확인. 향후 안내: 내부 보강 설명용 개념도 · 제품별 상이.

## 다음 단계
모션 확대는 사용자 검토 후 결정. 현재 방향에서 오른쪽 측벽이 가려지는 한계 때문에, 추가 재질 대비만으로 해결된다고 보장하지 않는다. 추가 시안·렌더는 진행하지 않았다.
