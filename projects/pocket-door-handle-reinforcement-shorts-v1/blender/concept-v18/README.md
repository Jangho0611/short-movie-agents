# v18 STATE3 카메라 검증

540×960 이미지 한 장만 렌더. 추가 부품·재질·조명 변경 없음. v17 원본을 읽어 STATE3 카메라만 변경했다. v14 외관 카메라 및 B 이미지 유지.

## 카메라
v17 방위각 +36도/고도48도에서 방위각 -12도/고도42도로 변경. 직교 scale 2.3 유지, 손잡이와 홈 주변 투영 범위로 재중심화. 고정 모델에서 오른쪽 홈 측벽을 보기 위해 시점을 반대쪽으로 넘겼다. 양쪽 측벽은 반대 방향 법선을 갖는 평면이므로 단일 직교 카메라에서 양쪽 내부 측면을 동시에 보는 것은 불가능하다.
렌더 없이 9개 후보 좌표/가시성을 평가한 뒤 하나만 렌더. 선택 구도 오른쪽 측벽 16/16 표본 가시, 왼쪽 측벽 0/16. 대응 중심의 화면상 간격 193.02px →157.65px(약18.3% 감소). 이는 중심 기준 지표이며 전체 메시지 이해의 증거는 아니다.

## 보존과 간섭
STATE3 카메라 외 모든 객체 메시 정점·면·행렬 보존. 재질/광원 변경 없음. 수평 단면 기준과 보강 영역 위치/범위 유지. 단일 가공홈 유지. 새로운 고체나 공개창 없음. 기존 비간섭 관계 유지. 실제 제품 치수나 설치 적합성 검증이 아니다.

## 시각 QA
단면 표시된 손잡이는 화면 안에 모두 들어옴. 원본 손잡이 상부는 기존 수평 단면 처리로 생략되는 것임. 외피·홈·목재색·금속 구분 유지. 오른쪽 목재색의 상면과 내부 측면 연결이 확인됨. 왼쪽은 여전히 상면만 보이므로 양쪽 깊이 동등성 미충족. 손잡이와 홈의 화면상 거리가 감소하고 가로 이격이 줄었지만, 동일 설치 위치를 직관적으로 전달하는지는 부분 충족. 손잡이가 홈 하단을 일부 가림. 전체 시각 QA는 PASS 아님, 사용자 검토 대기.

540×960에서 요소별 색상과 오른쪽 깊이는 읽히나 양쪽 보강 확인 메시지가 무자막으로 충분히 전달된다고 주장하지 않는다. 실제 제조사 목재 보강 배치 또는 균일 심재로 오인할 가능성 남음. 향후 안내: 내부 보강 설명용 개념도 · 제품별 상이.
