# v16 STATE 3 수평 단면 테스트

540×960 PNG 1장만 렌더. v14 B 미수정/미렌더. 모션·TTS 생성 없음.

## 구성 및 보존
v14 결합 전 모델의 원본 손잡이·문짝 메시와 행렬 및 원본 카메라 보존. 표시용 복사 객체에만 수평 반공간 INTERSECT modifier를 적용해 윗부분을 렌더에서 생략했다. 실제 가공홈 크기·위치·깊이는 변경하지 않았다. 원본 객체는 새 파일에서만 렌더 비활성화했다. 별도 공개창·계단형 절개·X-ray 없음.

단면 높이 Z=0.07699999213218689(가공홈 중심, 개념 상대 좌표). STATE 3 신규 직교 카메라: 가로 사선 36도, 고도 48도, 축척 2.05. 주시점은 홈 중심의 문짝 앞면이다. 기존 외관 카메라는 변경하지 않았다.

## 확인 영역
홈 양옆 단면에 낮은 채도의 사선 패턴 재질만 적용했다. 별도 부품이나 실물 보강재를 생성하지 않았다. 홈 좌우 경계로부터 상대값 0.025 바깥에서 시작하며 깊이 Y=-0.17~0.17, 문짝 앞뒤 사이에 한정한다. 매립 공간과 교차하지 않는 재질 표시다. 실제 재료·배치·시공 규격이 아니다.

## QA
기하/보존: 원본 정점·면·행렬과 v14 카메라 동일. 원본 홈 1개 유지. 확인 영역과 홈의 범위 비간섭. 실제 제조사 규격 검증 아님.
시각: 위쪽 사선에서 홈 깊이와 단면은 보인다. 표시 영역이 떠 있는 부품으로 보이지는 않는다. 다만 패턴이 표면 도색처럼 읽히며 보강 조건을 확인한다는 메시지를 단독 이미지로 전달하기 부족하다. 앞뒤 표면의 구분은 외곽 경계에 의존하며 내부 구성 설명은 제한적이다. 손잡이 하단이 프레임 경계에 걸린다. 따라서 전체 시각 QA는 PASS 아님/승인 보류. 모바일에서도 무음 메시지 전달은 미충족.

실제 꽉 찬 심재 문짝이나 특정 보강 배치로 오인할 위험이 남는다. 단면 내부의 균일 면은 관찰용 단면 채움이지 확인된 심재가 아니다. 향후 안내: 내부 보강 설명용 개념도 · 제품별 상이.
