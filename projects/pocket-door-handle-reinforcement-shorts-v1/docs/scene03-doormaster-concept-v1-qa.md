# Scene 3 문도사 정지 콘티 v1 QA

## 제작 범위
Remotion Still 1080×1920 PNG 한 장 및 동일 이미지의 360×640 축소본. 모션/영상/TTS 생성 없음. Scene1·2, Scene4·5, 공통 가이드/엔딩 변경 없음.

## 레이어와 위치
공통 배경을 기존 Pillow center-fit으로 재사용. 기존 B1 Recess review=false 재사용, 자막 포함 B1 PNG와 실패 B2 미사용.
단일 홈: x449,y576,w180,h768. 설치 중심 (539,960)으로 기존 540 기준(269.5,480)의 정확히2배.
실선 설치 기준 y960, 점선 가상 확인 영역 x358,y670,w362,h100, 중심y720. 예시 높이 차240px는 화면 설명용이며 실제 오차/규격 아님. 실제 보강재 개수/재료/치수/체결 구조를 그리지 않음. 점선은 공간 표시이며 중앙의 빈 홈을 가로지르는 실물 부품 아님.

## 문도사/안전 영역
Apple SD Gothic Neo,Noto Sans KR,sans-serif, 핵심 굵기900. #F4F1E9/#303431/#FFE600/#343735. 상단 패널y250–500, 핵심 자막2줄. 강조는 '위치가 다를 수'. 본문이 제품보다 위에 위치.
필수 안내 y1450,font40(모바일 약13.3px). 기존 작은 안내보다 판독성 확보. 라벨 font42/36, 보조32. 모션 없음, stroke3.07, 그림자없음.
임시 제작 안전 영역을 적용하였으나 실제 기기/플랫폼에서 검증된 공통 좌표로 주장하지 않음. 이번 실기기 캡처/아이폰 재생 없음. Dynamic Island/노치 위험은 상단 여백으로 낮추었으나 실제 가림 해소 미확인. 플랫폼 UI 또한 미확인.

## QA
- 기술 PASS: 단일 홈, 기존 설치 중심 유지, 기존 배경/제품/B1 설정의 기록 SHA256 일치. 승인 TTS6.880초 확인, 원본 읽기만 수행.
- 시각(360×640 직접 이미지 확인): 설치 실선과 위쪽 점선 영역, 간격 비교 표시가 구분됨. 제목/홈 겹침 없음. 핵심 문구 및 하단 안내 읽힘. 라벨은 의미는 식별되지만 보조 글씨는 작음.
- 전달력 조건부: 점선 가상 영역은 실제 보강재 아님을 표시했으나, 시청자가 특정 보강 높이로 받아들일 가능성 남음. 실제 문짝의 불일치를 확인한 장면이라고 주장하지 않음. 사용자 시각 승인 필요.
- 실기기/Shorts/Reels/Clip UI QA: 미확인. 가상 검토를 실제PASS로 선언하지 않음.

## 사용자 확인
두 높이의 차이가 즉시 읽히는지, 점선이 물리적 보강재로 오해되지 않는지, 안내/라벨 모바일 가독성을 확인 후 모션 진행 여부 결정. 이번에는 정지 콘티만 제작.
