## 시각 QA와 한계
360×640 정지 PNG 직접 확인: A 포괄/B 일부 이탈 구분, B 상단25px 노란 윤곽 식별, 라벨 및 도식 겹침 없음. 라벨40px는 모바일13.3px, 안내38px는12.7px로 읽히지만 작은 안내의 실기기 판독성은 사용자 확인 필요. 웜화이트#F4F1E9,본문#303431,강조#FFE600,외곽#343735와 기존 굵은 한글 폰트 체계 유지.

필수 텍스트는 프로젝트의 잠정 안전 영역을 참고해 배치. 고정 좌표를 모든 플랫폼의 공식 안전 영역으로 주장하지 않음. Dynamic Island·노치·Shorts/Reels/Clip 실제 UI 및 실기기 QA: 미확인. 실제 DOM 텍스트 바운딩박스 실측 대신 소스 배치와 렌더 정지 화면 확인이므로 모든 장치 안전 PASS는 아님.

ffplay 기본1배속,360×640으로 전체 재생 실행 후 exit0 확인. 다만 모델이 재생 영상·음성을 직접 연속 지각하지 못했으므로 연속 시청·청취 QA, 정확한 발화-자막 의미 동기, 질문/억양/클릭·팝 평가는 확인 불가. 기술 QA를 청각·시간적 시각 QA PASS로 대체하지 않음.

## 기술적 오인 위험
2D 위치 관계 비교로 실사 부재·체결 방식·재료·개수·치수를 제시하지 않음. 안내 '내부 보강 설명용 개념도 · 제품별 상이' 유지. A의 포괄 관계를 실제 필수 보강 범위 또는 설치 가능 판정으로 오해할 가능성은 남음. 기술적 적합성은 검증 대상이 아니며 PASS 판정하지 않음.
