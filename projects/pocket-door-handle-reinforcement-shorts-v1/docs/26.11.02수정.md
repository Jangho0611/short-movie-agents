## 공식 도면 시각 검증
- 출처 https://www.sugatsune.com/content/site-assets/201B_PDF/71.pdf (인쇄 71쪽).
- 원본 PDF docs/sugatsune-zl2501-official-p71.pdf 보존. 2600px 및 6000px 래스터로 직접 확인.
- 확대 검증 이미지 public/assets/images/official-section-verified-detail.png.
- 원형 오목 본체, 별도 링형 장착 브래킷, 본체가 브래킷 앞을 덮는 관계 확인.
- A–A′ 단면의 위·아래 목재 나사는 문 면에서 안쪽으로, 문 면에 대체로 수직 방향. 도면상 Ø4.6/Ø7, n2×Ø2.5, 8 표기도 확인.
- ZL-2501-56 표: D1=56, D2=32, D3=40, P=47, H1=3.2, H2=14, H3=16, H4=15, n1=2, n2=4 (mm, 개수 제외). 포함 목재 나사 3.1×16.
- 도면은 본체/브래킷 형상과 치수의 근거. ØD3 윤곽은 본체 기준의 매립 공간 개념으로 사용. 공구 가공 공차·접합부 세부 체결 규칙·고정 강도·중공 문짝 적용 조건은 확인되지 않아 임의 구현하지 않음.
- 실제 브래킷 완성형 CAD 복제 없음. 원본 정면 도면 선을 투명화한 레이어와 치수 기반 강조를 사용.
- 제품 사진은 ZL-2501 시리즈 공식 사진 전체를 보조 인용. 외형 상태의 중앙 원형은 D1/D2 기반 단순화 벡터이며 실사 합성 또는 정밀 제품 재현이 아님.
