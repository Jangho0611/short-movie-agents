## 10초 모션 비교
- 8초 파일은 10초에 가속 없이 수용 가능. 파일 종료 후 2초, 검출 발화 종료 후 약 2.22초 여유.
- 현재 B2 2.5–6.0초와 비교하면 세 번째 검출 발화 구간 끝이 약 0.28초 늦다.
- 의미 대응이 청취에서 확인되면 B2 종료를 약 6.4초로 0.4초 연장하고 B1 복귀를 6.4–8.0초로 줄이는 최소 조정 권장. 마지막 A 8.0–10.0초와 전체 10초 유지 가능.
- B2 첫 강조는 두 번째 의미 단위가 시작되는 약 3.19초에 맞추고 보강 강조는 약 4.86–6.28초 안에 배치하는 안을 검토. 현재 영상/자막/모션은 변경하지 않음.
- 전체 길이 연장 필요성은 현재 수치상 없음. 의미별 타이밍은 사용자 청취 후 확정.
