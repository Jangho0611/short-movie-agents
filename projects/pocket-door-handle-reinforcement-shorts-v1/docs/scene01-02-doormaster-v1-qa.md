# Scene 1–2 문도사 v1 QA

## 결과
- Scene 1: 1080×1920, 30fps, H.264, 147frames/4.90s.
- Scene 2: 동일 규격, 165frames/5.50s.
- 연결 Preview: 312frames/10.40s. 전환 4.90s clean cut.
- 승인 WAV 원본을 PCM stream copy로 MP4에 mux. AAC 재인코딩 없음. 각 MP4 추출 PCM이 원본 WAV의 모든 샘플과 일치. PCM-in-MP4 미지원 플레이어에서는 음성 재생 호환성 문제가 있을 수 있음; 임의 AAC 변환하지 않음.

## 사용 자산/타이밍
- Scene 1 scene01-tts-v10.wav, Scene 2 scene02-tts-v4.wav. speed/pitch/gain 변경 없음.
- Scene 1 음량 기준(-50dB) 0.100–4.535s; Scene 2 0.587–5.099s. 청각적 단어 경계 확인과 구분.
- Scene 1 첫 프레임 질문 표시, 2.667s '구멍만' 노란 강조, 4.433s 설치 중심 짧은 기준선.
- Scene 2 0–2.80s '손잡이가 / 들어갈 공간', 2.80–5.50s '제대로 / 고정될 구조도 중요'. 마지막 문구와 함께 외부 괄호 및 확인 위치 라벨.
- 자막 전환은 clean cut/색 강조. 추가 카메라 이동/회전/줌/제품 삽입 없음.
- 승인 A 원본을 화면 두 배로 표시. B1은 기존 Recess SVG의 review=false 부분을 새 소스에 재사용하고 동일 Pillow center-fit 배경으로 재구성. 자막 포함 B1 PNG 사용하지 않음.
- 공통 중심 (539,960), 제품 크기270×880, 홈180×768(1080화면). 실제 타공 수치 아님.

- Scene 2 확인 위치 그래픽은 체결부/보강재의 배치가 아닌 설명용 범위. 나사/브래킷/접착/내부 구조 생성 없음.

## QA 판정
- 기술 PASS: 전체 3 MP4 정상 디코딩, 규격/프레임, 음성 원본 PCM 일치, A/B1 원본 자산 SHA256 일치. 승인 Scene 1 해시 일치.
- 정지 프레임 확인: 0/2.7/4.5/5.2/7.9/10.2초를 360×640으로 확인. 자막 잘림·제품 겹침 없음, 단일 홈 유지, 배경/중심 고정. 주요 문구 읽힘.
- 조건부: 작은 위치 라벨·하단 개념 안내는 모바일에서 작음. 핵심 메시지는 상단 자막으로 전달하나 사용자 확인 필요.
- 실제 연속 시청/청취 인지 QA는 확인 불가. 로컬 플레이어 실행 여부와 모델의 직접 시청/청취는 별개. 음성 자연스러움/정확한 단어 싱크/전환 리듬/클릭·팝 PASS를 선언하지 않음.
- 승인 Scene 1 원본에 있던 fullscale 샘플 특성은 보존. 새로운 클리핑은 PCM 동일성으로 배제하나 기존 클리핑이 없다고 선언하지 않음.
- 전체 시각·청각 QA 종합: 사용자 검토 대기. 기술 PASS만으로 최종 PASS 아님.
