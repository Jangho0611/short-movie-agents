## 시각 QA 및 한계
직접 비교 PNG를 열어 확인:전체 외곽의 오른쪽 이동은 정지 비교에서 해소. 인출부와 매립 베이스는 유지되며360×640에서 식별 가능. 자막과 제품 겹침 없음.
WARN:앞면 경계와 배경 바닥 원근은 다르며 완벽한 동일문짝 픽셀 전환 아님. 도어 상하 끝은 화면밖이라 전체 물리 크기 확인 불가.
ffplay360×640 정상속도 전체 재생 실행 및 정상종료. 모델 직접 연속 시청·청취를 입증할 수 없어 하드컷의 주관적 자연스러움/청각 품질은 미확인.
아이폰/Dynamic Island/노치 및 Shorts/Reels/Clip 실제 UI·실기기 재생 QA 미확인. 모바일 호환 인코딩을 사용했지만 실제 기기 PASS를 뜻하지 않음. 자막 기존 안전영역 유지.
