- 메인 자막: f0–93 첫 문장, f94(3.133초) 이후 기존 두 번째 문구 유지.
- A 강조: 기존1.000–2.800초 유지.
- B 강조: f136(4.533초)에 첫 비영 opacity .25, f139(4.633초)에 최대. f200(6.667초)부터 fade-out, f206(6.867초)에 완전 소멸. 마지막까지 도식 자체는 고정.
