## 최근 승인 본문 구현값 — 시리즈 공식 범용 토큰과 구분
- fontFamily: Apple SD Gothic Neo, Noto Sans KR, sans-serif; weight 900.
- 배경 #F4F1E9, 본문 #303431, 강조 #FFE600, 강조 외곽선 #343735.
- 1080px 기준 기본 100px/강조 107px, 강조 외곽선 3.66px, 상단 영역 298px. 5프레임 등장, 약한 12px 이동과 ease-out.
- 이 수치는 승인 사례의 구현값이다. 이 프로젝트의 구조를 가리지 않도록 추후 배치 검토하며 이전 자막 전체를 복제하지 않는다.
- 기존 컴포넌트의 두 번째 줄 전체 강조를 그대로 강제하지 않고 사용자 최신 지시인 핵심 단어 중심 절제된 강조를 우선한다. 새 색/폰트를 임의 추가하지 않는다.

## 향후 적용
- 최대 2줄, TTS 의미 단위 전환, 360×640 가독성 확인.

- 커버 간판/브러시/대형 제목 규칙과 본문 자막을 구분.

- TTS 통합 청취 승인 전 영상/자막 렌더 금지. 공통 가이드와 기존 자산 변경 없음.
