# SNS 업로드 문구 가이드

- 문서 버전: `v1.4`

향후 모든 Shorts 편의 SNS 업로드 문구에 재사용하는 공통 표준이다. 최종 영상과 Cover 승인 후 작성한다.

## 최종 출력 순서

| 플랫폼 | 출력 순서 |
|---|---|
| YouTube Shorts | 제목 → 설명 → 고정 프로모 블록 → 해시태그 → 고정댓글 |
| Instagram Reels | 본문 → 고정 프로모 블록 → 해시태그 → 고정댓글 |
| Naver Clip | 제목 → 설명 → 해시태그 → 글자 수 QA (고정댓글 없음) |

## 캡션 톤과 상세 설명

- YouTube/Instagram 설명은 TTS나 화면 자막의 복사·단순 요약이 아니다. 영상은 짧게 전달하고 SNS 설명은 내용을 더 자세히 이해시키는 역할로 분리한다.
- 기본 구조는 **핵심 결론 → 왜 그런지/원리·이유 → 실제 현장·사용에서의 의미 → 적용처·선택·시공 시 확인할 점 → 구매·가격·대량구매·납품 관련 정보**다.
- 영상에서 확정되지 않은 사실이나 가격을 새로 만들지 않는다. 영상에서 짧게 말한 사실은 자연스럽고 충분한 문장으로 풀어쓴다. 특히 Hook/결론을 거의 그대로 옮긴 2~3문장으로 끝내지 않는다.
- 검색 표현을 해시태그에만 맡기지 않는다. 제품명·자재명·공법명·용도·가격·대량구매·납품 등 관련 키워드를 본문 문맥에 자연스럽게 포함하고 키워드 나열식 문장은 쓰지 않는다.

## 고정 프로모 블록 (YouTube / Instagram)

상세 설명 뒤에 빈 줄을 두고 아래 블록을 그대로 넣은 다음, 다시 빈 줄을 두고 해시태그를 배치한다.

```
────────────────────────────────────
건축자재가 필요하시다면
대산에서 쉽고 빠르게 확인해 보세요.
🌐 daesan.ai
전국 납품 및 대량 구매 상담 가능합니다.
────────────────────────────────────
```

- 위·아래 구분선 모두 필수이며 문구를 축약·변경하지 않는다. 본문 중간에 홍보 문구를 섞지 않는다.
- 도메인은 위 블록에 있으므로 설명 본문에 `daesan.ai`를 중복 표기하지 않는다.
- 고정댓글은 별도로 작성한다. 질문형 참여 유도 + 필요 시 `daesan.ai` 안내를 자연스럽게 포함한다.

## 해시태그 구성

YouTube / Instagram / Naver Clip 모두 **최대 5개**다. 기본 구성과 순서는 다음과 같다.

1. 자재 핵심 키워드
2. `#건축자재` (고정)
3. `#대량구매` (고정)
4. 해당 핵심 자재명에 맞춘 가격 키워드
5. 자재 관련 핵심 키워드

- 고정 2개와 가격 태그 외 나머지 2개는 주제 설명력과 검색 가치가 높은 자재·제품 키워드를 선택한다. 브랜드/제품명이 실제 영상 핵심이면 이 자리에 사용할 수 있다.
- `#릴스 #reels`는 기본 사용하지 않는다. 관련 없는 태그를 숫자 채우기용으로 넣지 않는다.

| 주제 | 기본 5개 예시 |
|---|---|
| XPS | #XPS #건축자재 #대량구매 #XPS가격 #XPS단열재 |
| 도어 | #도어 #건축자재 #대량구매 #도어가격 #ABS도어 |
| 석고보드 | #석고보드 #건축자재 #대량구매 #석고보드가격 #방수석고보드 |

### 통용 검색명 활용

- 자재 핵심 키워드·자재 가격 키워드·자재 관련 키워드를 선정할 때 정확한 자재명만 기계적으로 사용하지 않는다. 실제 고객·현장에서 널리 사용하는 통용명 또는 검색명이 있고 해당 영상의 자재를 정확히 가리키는 경우, 검색용 해시태그에서는 그 통용 검색명을 우선 활용할 수 있다.
- 본문에서는 정확한 자재명·제품 분류를 유지한다. 통용 검색명을 정확한 자재명 대신 사실 설명에 사용해 의미를 왜곡하지 않는다.
- 실제 해당 자재를 가리키는 경우에만 적용하며 관련 없는 인기 검색어를 붙이지 않는다. 가격·시공 키워드도 같은 검색어 체계를 유지한다.
- 예: 본문은 `XPS`, 해시태그는 `#아이소핑크 #건축자재 #대량구매 #아이소핑크가격 #아이소핑크시공`.
- 비교 콘텐츠에서는 마지막 관련 태그를 비교 대상에 맞게 조정할 수 있다. 예: `XPS vs EPS`는 `#아이소핑크 #건축자재 #대량구매 #아이소핑크가격 #EPS`.
- 이 예시는 본문의 정확한 자재명 `XPS`를 `아이소핑크`로 전부 치환한다는 뜻이 아니다. 기존 **최대 5개 해시태그** 정책은 그대로 유지한다.

## 네이버클립

- 각 편 SNS copy MD에 네이버클립 전용 섹션을 둔다. 제목과 설명을 별도로 작성하고, 긴 고정 프로모 블록과 고정댓글은 넣지 않는다.
- `daesan.ai`는 클릭 링크가 아닌 텍스트 사이트명으로 자연스럽게 사용할 수 있다.
- 설명은 제품 특징 → 이유/원리 → 현장 의미 → 적용/선택 포인트 → 구매 관련 정보 순으로 허용 범위 안에서 충실하게 작성한다. 해시태그를 줄인 만큼 설명의 정보량을 늘리며 TTS를 복사하지 않는다.
- 설명 마지막에 기본 해시태그 5개를 배치하되 관련 키워드가 부족하면 숫자를 채우지 않는다. 최대 5개 규칙은 동일하다.
- **공식 확인(2026-09-22):** [클립 고객센터의 동영상 제작 방법](https://help.naver.com/service/30048/contents/24422?osType=COMMONOS)은 네이버앱·클립 크리에이터 앱·PC 웹의 동영상 설명을 **최대 300자**, 해시태그를 **최대 5개**로 안내한다. 게시물 클립과 혼동하지 않는다.
- 위 공식 안내에는 별도 제목 제한이 명시돼 있지 않으므로 제목은 **플랫폼의 현재 허용 글자 수 이내**로 작성하고 실제 업로드 경로에서 최신 제한·제목 입력란 유무를 확인한다. 네이버TV용 [클립 기본 정보 안내](https://help.naver.com/service/17223/contents/23505)의 수치를 전체 클립 경로에 일괄 적용하지 않는다.
- 제목과 실제 업로드할 설명(본문·줄바꿈·해시태그 포함)의 글자 수를 각각 계산해 QA에 표기한다. 업로드 시 최신 공식 안내와 입력 화면의 계산·제한을 재확인하고, 확인되지 않는 경로에는 새 숫자를 추정하지 않는다.

## Instagram 계정명

- Instagram 캡션에는 계정명(`daesan_wood` 등)을 텍스트로 포함하지 않는다.
- 계정명은 UI에 자동 표시되므로 중복하지 않는다.

## 지역 문구

- 지역명(안양 등)을 사용한 단순 해시태그나 홍보 문구는 사용하지 않는다.

## 기존 승인 SNS 재작성

공통 규칙 변경 후 사용자가 새 기준 적용을 지시하면 기존 승인 SNS를 보존하고 새 버전 또는 최신 최종본을 별도 파일로 저장한다. 기존 파일을 덮어써 과거 기록을 잃지 않는다. 영상·Cover·TTS는 수정하지 않으며 특별한 이유가 없으면 기존 제목·핵심 메시지를 유지한다. 상세 설명, 프로모 구분, 해시태그 정책만 새 기준에 맞게 갱신한다.
