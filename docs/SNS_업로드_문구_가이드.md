# SNS 업로드 문구 가이드

- 문서 버전: `v1.2`

향후 모든 Shorts 편의 SNS 업로드 문구에 재사용하는 공통 표준이다.

## 캡션 톤

- 자막을 그대로 복사하지 않고, 사람이 설명하듯 자연스럽게 풀어쓴다.
- TTS/자막 원문을 SNS 본문에 그대로 재사용 금지. 특히 Scene1(Hook)과 마지막 Scene(결론) 문구를 SNS 본문에 거의 그대로 가져오지 않도록 주의 - SNS 문구는 영상 대본을 그대로 옮기는 게 아니라, 결론→이유→적용처 순서의 독립된 요약문이어야 함.

## 해시태그 구성

아래 순서로 구성한다.

1. 영상별 핵심 키워드
2. 인테리어/자재 관련 키워드 다수 포함
3. 대산 고정 태그
4. Instagram만 `#릴스 #reels` 추가

- 가격 관련 키워드는 주제 관련성과 무관하게 매 편마다 항상 포함한다.
- 대산 고정 해시태그 8종: #인테리어자재 #건축자재 #건축자재정보 #건축자재유통 #건축자재납품 #대량자재구매 #대산 #대산종합건축자재

## 네이버클립

- 제목은 `24자 이내`, 설명은 해시태그를 포함해 `200자 이내`로 작성한다.
- TTS·자막 원문을 그대로 복사하지 않고 자연스러운 구어체로 압축한다.
- 글자 수가 제한될 때는 `결론 > 이유 > 적용처` 순서로 내용을 우선한다.
- 각 편 SNS copy MD 안에 `네이버클립` 전용 섹션을 별도로 작성한다.
- 제목과 설명의 실제 글자 수를 섹션에 표기한다. **설명은 본문+모든 줄바꿈+해시태그를 모두 합산해 200자를 넘지 않으면서 최대한 200자에 근접하게 채운다.** 본문이 짧을 경우 주제와 관련된 해시태그를 추가해 남는 글자 수를 보충한다.

## Instagram 계정명

- Instagram 캡션에는 계정명(`daesan_wood` 등)을 텍스트로 포함하지 않는다.
- 계정명은 UI에 자동 표시되므로 중복하지 않는다.

## 지역 문구

- 지역명(안양 등)을 사용한 단순 해시태그나 홍보 문구는 사용하지 않는다.

## 고정댓글

- 질문형 문장으로 참여를 유도한다.
- `daesan.ai` 홍보 문구를 포함한다.
