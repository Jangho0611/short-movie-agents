# DoorMaster — 문도사의 그것이 알고싶도어

- 버전: v1 / 2026-10-13
- 상태: 사용자 검토·승인 대기
- 용도: 대산 도어 시리즈 전용 정지 커버 가이드. 영상 본편 디자인 규격이 아니다.
- 적용 범위: 도어·문틀·문선·몰딩 관련 비교형, 정보형, 문제 해결형 커버
- 작성 근거: 사용자가 지정한 「기존 문틀, 슬림하게 바꿀 수 있을까?」 승인 시안의 설명 및 아래 기존 문서

## 1. 근거와 적용 우선순위

1. 사용자의 최신 명시 지시와 해당 커버 승인본
2. 해당 프로젝트 최신 작업기록
3. [대산 제작 지침 v2.10](../../daesan_shorts_instructions.md) §0, §5 및 [COVER.md v1.5](../../COVER.md)
4. [Shorts 제작 운영가이드](../../Shorts_제작_운영가이드.md) §14, §23 및 [공통 Visual Grammar](../../건축자재_AI이미지_품목별_프롬프트_가이드.md)
5. 이 도어 시리즈 가이드와 [디자인 라이브러리](../README.md)의 참고 문법

실제 제품 형상은 승인 Canonical Reference가 우선한다. 스타일 문서는 실제 제품 구조를 증명하지 않는다. 이 문서는 외부 브랜드 관찰 자료가 아닌 대산 자체 시리즈 가이드이며, 기존 10종 외부 reference와 구분한다.

사용자가 설명한 승인 커버의 실제 이미지·구현 소스 경로는 이번 확인에서 특정하지 못했다. 원본을 직접 측정하거나 시각 QA했다고 주장하지 않는다. 아래 색상 역할·구성 방향은 사용자 지시이며, 도어 커버 전용 수치 규격은 원본 확인 후 확정한다.

## 2. 디자인 콘셉트

따뜻하고 밝은 바탕에 실제 도어 자재와 큰 검정 제목을 배치하는 전문 정보 콘텐츠다. 시리즈명·문 아이콘으로 반복 인지성을 만들고, 노란 핵심어와 기존 대산 브랜드 서명으로 대산 숏폼과 연결한다.

시각적 우선순위는 **메인 제목 → 자재 이미지 → 부제 → 시리즈 타이틀·문 아이콘 → 브랜드 서명**이다. 읽는 순서상 시리즈는 상단에 있지만 메인 제목보다 크게 보이지 않는다. 일반 커버의 유색 제목 카드·대산이 캐릭터를 도어 시리즈의 고정 요소로 가져오지 않는다.

## 3. 색상 체계와 확정 상태

| 역할 | 적용 기준 | 근거·상태 |
|---|---|---|
| 전체 배경 | 웜화이트 | 사용자 확정 방향. 승인 커버의 정확한 HEX는 미확인 |
| 메인 제목 | 강한 블랙 | 사용자 확정 방향. 정확한 HEX는 원본 확인 후 기록 |
| 핵심어 | 노란색 계열 | 사용자 확정 방향. 정확한 HEX·외곽선 수치는 미확인 |
| 부제·보조 글자 | 밝은 배경에서 충분히 읽히는 어두운 중립색 | 역할 기준. 별도 공식 HEX를 신설하지 않음 |
| 브랜드 서명 | `#123628` | 제작 지침 §5.2의 승인 로고 실측값. 원본 로고 색·비율 보존 |

`#146335`는 기존 tokens.ts 값으로, 커버 Brand Lockup의 `#123628`과 혼용하지 않는다. 운영가이드의 네이비 `#2B4356`·오렌지 `#EB674E`는 기존 일반 템플릿의 사례이며 도어 시리즈 팔레트로 전용하지 않는다.

004 영상 단면의 `#F7F5F0`, `#303431`, `#FFE600`은 영상 소스에서 사용한 값이지 승인 도어 커버에서 측정한 값이 아니다. 커버 공식 코드로 자동 승격하지 않는다. 노란 글자가 묻히면 승인 시안의 어두운 외곽선·주변 대비를 우선 확인하고 최소 보정한다. 배경 전체를 검정으로 바꾸거나 새 강조색을 늘리지 않는다.

## 4. 타이포그래피

기존 커버 폰트는 Pretendard다. 영상 단면에서 사용한 Apple SD Gothic Neo를 커버 표준으로 자동 전환하지 않는다.

| 요소 | 기존 커버 근거 | 도어 시리즈 적용 |
|---|---|---|
| 시리즈 타이틀 | Category: Pretendard-SemiBold 30px | SemiBold 계열 우선. 최종 크기·좌표는 승인 시안 확인 필요 |
| 메인 제목 | Pretendard-Black 60px, 줄간격 92px | Black 유지, 화면 내 가장 큰 비중. 수치는 기존 템플릿 참조값이며 도어 전용 확정값 아님 |
| 부제 | 별도 커버 부제 수치 미명시 | 같은 Pretendard 계열. 제목보다 작고 약하게, 실제 축소 화면으로 검증 |
| 브랜드 | DAESAN: Black 46px / 한글: Medium 26px | 기존 승인 Lockup 기준 유지 |

제작 때 실제 사용하는 폰트 파일과 굵기를 확인·보존한다. 폰트가 없으면 조용히 대체하지 않고 기록한다. 자간·행간·크기를 새로운 공식 수치로 임의 지정하지 않는다. 한글·제목·브랜드는 편집 가능한 후처리 레이어로 분리한다.

## 5. 상단 고정 시리즈 타이틀과 문 아이콘

- 고정 문구: **문도사의 그것이 알고싶도어**. 띄어쓰기와 표현을 임의 변경하지 않는다.
- 상단의 동일한 정렬 관계로 반복 사용한다. 줄바꿈·좌표·크기는 첫 승인 템플릿에 기록해 재사용한다.
- 문 아이콘은 시리즈 식별용 보조 요소다. 실제 자재 사진보다 강하게 보이지 않게 한다.
- 승인 아이콘 원본을 우선한다. 아직 확인되지 않은 아이콘 모양·선 두께를 공식 자산으로 확정하지 않는다.
- 문 아이콘은 대산 심볼을 대체하지 않는다. 대산이 캐릭터는 모든 도어 시리즈 커버에서 사용하지 않는다.

## 6. 제목과 부제 작성

### 메인 제목

콘텐츠마다 바꾸며, 하나의 질문이나 판단 포인트만 담는다. 기존 COVER.md의 기본 2~4줄을 출발점으로 의미 단위로 줄을 나눈다. 글자를 줄여 억지로 넣기보다 문장을 간결하게 다듬는다.

- 기준 문구: 「기존 문틀, 슬림하게 바꿀 수 있을까?」
- 핵심어만 노란색으로 강조한다. 일반 템플릿의 마지막 줄 accent 원칙을 참고하되 승인 도어 시안의 강조 단어 배치를 우선한다.
- 제품명·핵심 질문이 모바일에서 즉시 읽혀야 한다.
- 검증되지 않은 성능·가격·시공 가능 여부를 확언하지 않는다. 과장된 공포나 무조건 교체/리폼을 유도하는 제목을 피한다.

### 부제

짧은 한 문장 또는 구절로 제목에 없는 핵심 정보를 보완한다. 제목을 반복하거나 공정 전체를 나열하지 않는다. 도어 시리즈는 부제를 구성 요소로 두되, 불필요한 부제 생략은 개별 승인에서 결정한다. 아래 예시는 문구 확정본이 아니다.

- 비교형: 「보강과 마감까지 비교」
- 정보형: 「문틀과 문선의 차이」
- 문제 해결형: 「상태에 따라 달라지는 선택」

## 7. 자재 이미지 배치

실제 제품 사진 → 승인 Canonical Reference → 승인된 재사용 자산 순으로 확인한다. 도어·문틀·문선·몰딩 중 제목에 직접 해당하는 자재를 화면의 주요 이미지로 둔다. 실사 이미지에 한글·로고를 굽지 않는다.

주요 자재의 외곽, 접합부, 표면이 제목이나 브랜드에 가려지지 않게 한다. 제품 형상·두께·비율을 클릭 유도 목적으로 변형하지 않는다. 얕고 자연스러운 그림자는 허용하지만 과장된 3D·장식 카드·불필요한 배지는 피한다.

비교형은 카메라 각도·축척·조명·공간을 맞춘다. 문짝 크기나 위치를 바꾸어 문선 폭 차이를 과장하지 않는다. 구조 미확정 개념도를 실제 시공 사진이나 검증된 단면으로 제시하지 않는다.

## 8. 9:16 출력과 플랫폼별 안전영역

**기존 내부 공통 기준:** 1080×1920 PNG, 중앙 1080×1080 크롭 `y=420~1500`. 이는 대산 내부 Feed Safe QA 기준이며 모든 플랫폼의 현재 공식 안전영역을 의미하지 않는다.

중앙 크롭 안에 메인 제목 전체·핵심 자재/비교 대상·DAESAN Brand Lockup을 유지한다. 부제가 없으면 의미가 달라지는 경우 부제도 보존한다. 상단 시리즈 타이틀은 기존 Category처럼 중앙 크롭 밖으로 나갈 수 있으나, 세로 원본에는 완전하게 표시한다. 정사각 화면에서도 시리즈명을 반드시 노출할지는 별도 확인 사항이며 이를 위해 승인 구도를 임의 이동하지 않는다.

| 플랫폼 | 적용·검증 | 아직 확정하지 않는 것 |
|---|---|---|
| YouTube Shorts | 9:16 원본, 내부 중앙 크롭, 실제 업로드 미리보기에서 제목·제품·브랜드 가림 확인 | 현재 화면별 노출 비율·UI 여백·커버 선택 방식의 고정 수치 |
| Instagram Reels / 프로필 | 9:16 원본과 내부 정사각 QA 보존. 실제 Reels·프로필 미리보기에서 추가 확인 | 현재 프로필 그리드가 항상 정사각이라는 가정, 기기별 고정 안전영역 |
| Naver Clip | 9:16 원본과 내부 공통 QA 후 실제 등록 화면에서 가림·크롭 확인 | 현재 썸네일 비율·상하좌우 UI 영역의 공식 수치 |

이번 문서 작성에서는 플랫폼 최신 정책을 조사·확정하지 않았다. 실제 업로드 전 공식 도움말 또는 업로드 UI에서 현행 표시를 확인하고 확인일·화면을 기록한다. 근거 없는 플랫폼별 픽셀 여백을 추가하지 않는다. 좌표 검사뿐 아니라 세로 원본·중앙 크롭·모바일 축소 화면을 직접 확인한다.

## 9. 브랜드 표기

기존 승인 구성 **[대산 심볼] / DAESAN / 대산종합건축자재**를 사용한다. 실제 프로젝트 엔딩의 승인 로고를 우선 확인한다. 공용 승인 자산 경로는 `assets/daesan-ending/logos/daesanlogo2.png`이며 제작 프로젝트 내부에 복사해 사용한다.

기존 기본값은 로고 78×78px, DAESAN 심볼 기준 x+90/y+7, 한글 x+90/y+61이다. 하단 배치는 구도에 따라 조절하되 중앙 크롭 안에서 제목보다 약한 브랜드 서명으로 유지한다. 불투명 흰 카드에 넣지 않는다. 로고의 종횡비·색을 바꾸거나 AI로 재생성하지 않는다. 공식 확인되지 않은 영문 슬로건·임의 회사명·태그라인을 추가하지 않는다.

## 10. 유형별 레이아웃

공통 골격은 상단 시리즈명+문 아이콘 → 가장 큰 메인 제목 → 짧은 부제 → 자재 이미지 → 브랜드 서명이다. 도어 전용 좌표는 아직 미확정이며 다음은 배치 원칙이다.

| 유형 | 이미지 구성 | 확인 항목 |
|---|---|---|
| A 비교형 | 기존/변경 또는 제품 A/B를 좌우 병렬로 배치. 필요한 경우 짧은 구분 라벨 후처리 | 동일 축척·각도, 양쪽 제품 모두 중앙 크롭에 유지, 비교 조건 명료 |
| B 정보형 | 대표 자재 하나를 크게 두고 필요한 세부 사진·부분 확대를 보조로 배치 | 제품 종류 즉시 식별, 라벨 과밀 금지, 대표 이미지보다 보조 컷이 커지지 않음 |
| C 문제 해결형 | 문제 부위가 보이는 실제 도어 사진 중심. 필요할 때 해당 부분 확대 | 손상 과장 금지, 문제 위치 명료, 해결 조건을 부제로 보완 |

주제에 따라 이미지 영역만 바꾸고 시리즈명·문 아이콘·Pretendard·웜화이트/블랙/노랑의 역할·브랜드 위계를 유지한다. 첫 유형별 시안 승인 후 실제 좌표·자산·색상·폰트 값을 기록한다. 기존 일반 커버의 박스 좌표 `(53,341)~(770,694)`나 점 인디케이터를 새 시리즈의 의무 요소로 복제하지 않는다.

## 11. 금지 요소

- 대산이 캐릭터, 미승인 영문 슬로건, 생성형 로고·한글
- 전체 검정 배경, 과도한 유색 카드, 무관한 장식·과장된 3D
- 제품 폭·두께·문짝 크기 변경을 통한 비교 왜곡
- 확인되지 않은 시공 단면·수치를 실제 제품 규격으로 단정
- 외부 DESIGN 문서의 브랜드 색·전용 폰트를 대산 표준으로 차용
- 승인된 커버·영상·기존 가이드 덮어쓰기 또는 무단 삭제
- 커버를 만들기 위한 본편·TTS·첫 씬 임의 변경

## 12. 제작·승인·보존 절차

1. 최종 영상 승인 여부와 최신 지시·작업기록 확인.
2. 이 가이드와 COVER.md, 실제 승인 도어 커버·문 아이콘·로고·폰트 자산 확인.
3. 커버 유형, 제목, 부제, 제품 reference를 정하고 미확정 사항 구분.
4. 기존 자산 재사용 여부 판단. 이미지 생성은 명시 요청이 있을 때만 진행.
5. 제품·텍스트·시리즈 타이틀·아이콘·브랜드를 독립 레이어로 구성.
6. 제품 정확도, 세로·중앙 크롭·모바일 가독성 QA. 플랫폼별 현행 표시 확인.
7. 버전 파일로 저장하고 사용자 커버 승인 대기. 영상 승인과 커버 승인을 혼동하지 않음.
8. 승인본, 크롭 QA, 편집 소스, 직접 참조 자재·로고·폰트, 사용 수치와 자산 출처를 함께 보존.

프로젝트 커버는 `public/covers/`, 크롭 QA는 `public/covers/qa/`에 저장한다. 이전 버전은 보존한다. 이 문서 작성은 커버 이미지 제작·수정·업로드 승인이 아니다. 이번 작업에서 이미지 생성, Git commit/push는 진행하지 않는다.

## 13. 최종 QA 체크리스트

- [ ] 시리즈명이 「문도사의 그것이 알고싶도어」와 정확히 일치한다.
- [ ] 승인 문 아이콘을 사용하고 메인 제목이 가장 큰 시각적 비중을 갖는다.
- [ ] 웜화이트·블랙·노란색의 역할과 Pretendard 계열을 유지한다.
- [ ] 미확인 색상·폰트 크기·좌표를 공식 규격으로 단정하지 않았다.
- [ ] 노란 핵심어가 밝은 배경에서도 읽히며 부제가 제목을 반복하지 않는다.
- [ ] 제품 외형·재질·비율이 reference와 일치하고 비교 조건이 동일하다.
- [ ] 대산이 캐릭터와 미승인 영문 슬로건이 없다.
- [ ] 승인 로고와 정확한 브랜드 표기·색상·비율을 유지한다.
- [ ] 1080×1920 원본과 중앙 y=420~1500 크롭을 실제 시각 QA했다.
- [ ] 제목 전체·핵심 제품·브랜드가 중앙 크롭에 남으며 겹치지 않는다.
- [ ] 플랫폼별 현재 미리보기 확인과 내부 안전영역 QA를 구분해 기록했다.
- [ ] 이전 버전을 보존했고 소스·폰트·직접 참조 자산을 함께 저장했다.
- [ ] 사용자 승인을 받기 전 결과를 최종 승인본으로 표시하지 않았다.

## 14. 확인이 필요한 사항

- 사용자가 지정한 승인 커버 원본·편집 소스의 실제 경로와 최종 버전.
- 해당 원본의 웜화이트·블랙·노랑 HEX, 제목·부제의 크기·좌표·줄바꿈.
- 승인 문 아이콘 파일과 배치 규격.
- 상단 시리즈명을 정사각 크롭에서도 필수로 노출할지 여부.
- 실제 업로드 시점의 플랫폼별 노출 비율·UI 가림·커버 설정 방식.

위 항목은 임의 수치로 채우지 않는다. 이번 문서는 사용자 설명에 근거한 시리즈 방향과 확인된 기존 공통 기준을 정리한 검토본이다.
