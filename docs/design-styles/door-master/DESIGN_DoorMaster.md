# DoorMaster — 문도사의 그것이 알고싶도어

- 버전: v4 / 2026-10-13
- 상태: 최신 사용자 지시 반영 완료 / 문서 최종 확인 대기
- 용도: 도어 시리즈 전용 커버의 독립 디자인·제작·QA 기준
- 범위: ABS도어, 문짝, 문틀, 문선, 몰딩, 도어 시공 및 관련 자재 콘텐츠
- 본 문서 정리는 기존 커버의 최종 승인이나 새 이미지 제작 승인을 의미하지 않는다.

## 1. 독립 시스템과 적용 원칙

DoorMaster는 기존 대산 COVER.md의 디자인 템플릿을 변형하거나 확장한 시스템이 아니다. 최초 ChatGPT 디자인 레퍼런스에서 출발한 독립적인 시리즈 전용 디자인 시스템이다.

디자인 판단 순서는 다음과 같다.

1. 사용자의 최신 명시 지시와 해당 에피소드에 대한 승인 범위
2. [최초 ChatGPT 시각 레퍼런스](./references/door-master-cover-reference-v1.png)
3. 본 문서의 현행 디자인 규칙

레퍼런스는 구도·타이포그래피·색의 역할·이미지 비중을 판단하는 기준이다. 실제 제품 구조·시공 치수·성능의 검증 자료는 아니다. 사실 정확성과 승인된 브랜드 자산의 사용 원칙은 디자인 재현을 이유로 완화하지 않는다.

[COVER.md](../../COVER.md)와 [daesan_shorts_instructions.md](../../daesan_shorts_instructions.md)는 브랜드 자산의 정확성, 사용자 승인, 파일 보존, 임의 삭제 금지 등 대산 전체 운영 원칙 확인에만 적용한다. 일반 커버의 디자인 좌표·레이아웃·타이포그래피·포인트 컬러·카드 구조는 DoorMaster에 적용하지 않는다. 이 문서는 다른 대산 시리즈나 공통 가이드의 규칙을 변경하지 않는다.

## 2. 최초 레퍼런스와 시리즈 정체성

레퍼런스 실제 이미지에서 확인한 특징은 다음과 같다.

- 웜화이트 바탕, 자연광과 부드러운 그림자로 만든 프리미엄 인테리어 매거진 분위기.
- 기울어진 외곽과 높이 차이가 있는 비대칭 블랙 간판. 문 아이콘이 우측 위로 솟아 제목과 하나의 디자인 요소를 이룸.
- 「문도사의」는 상대적으로 작고 노란색, 「그것이 알고싶도어」는 더 큰 흰색 중심 글자이며 끝의 「도어」는 우드톤. 간판에는 절제된 우드톤 테두리가 있음.
- 매우 크고 굵은 블랙 메인 제목. 줄마다 크기와 시작점이 다른 비대칭 배치.
- 핵심 단어 뒤에 가장자리가 불규칙한 노란 브러시형 하이라이트. 반듯한 정보 카드나 단순 색상 박스로 대체하지 않음.
- 제목보다 작은 부제, 필요한 경우 제품을 직접 가리키는 라벨과 연결선.
- 화면 하단을 크게 채우며 좌우·하단 밖으로 이어지는 제품 이미지. 별도의 작은 사각 사진 틀에 담지 않음.
- 블랙·노란색·웜화이트·우드톤의 조합과 자연스러운 입체감.

레퍼런스의 두 문틀, 비교 화살표, 흰 문선과 우드 도어는 해당 에피소드의 표현이다. 모든 제품을 같은 색·재질로 바꾸거나 같은 제품 수를 강제하지 않는다. 미승인 영문 슬로건 「INTERIOR SOLUTION」은 디자인 기준에서 제외한다.

특정 픽셀 좌표보다 큰 제목과 큰 제품의 관계, 비대칭 간판, 브러시 강조의 시각적 위계를 유지한다. 대산이 캐릭터는 사용하지 않는다.

## 4. 제목·부제·문자 관리

메인 제목은 한 가지 핵심 질문이나 메시지에 집중한다. 문장 길이에 맞춰 의미 단위로 나누고 줄별 크기·기울기·시작점의 차이를 활용한다. 특정 줄 수나 일반 커버의 글자 크기·행간을 강제하지 않는다. 핵심 단어만 노란 브러시로 강조하며 글자가 배경에 묻히지 않게 한다.

부제는 제목보다 작게 배치해 핵심 정보를 짧게 보완한다. 제목 반복, 공정 전체 나열, 불필요한 설명 문구는 넣지 않는다. 부제 생략 여부는 해당 에피소드 승인에서 결정한다.

반복 교체할 제목·부제는 편집 가능한 문자 레이어로 관리한다. 시리즈 간판, 제품 이미지, 라벨, 브랜드도 분리해 교체·검증 가능하게 보존한다. 레퍼런스에 글자가 포함돼 있다는 이유로 새 제목까지 이미지에 합쳐진 상태로만 관리하지 않는다.

레퍼런스의 실제 폰트는 확인되지 않았다. 특정 폰트를 원본 폰트라고 단정하거나 기존 일반 커버의 Pretendard 규칙을 자동 적용하지 않는다. 실제 제작에 선택한 폰트·굵기·자간·기울기와 자산 출처를 기록하고 사용자 시각 승인 후 재사용한다. 레퍼런스의 형태와 위계가 판단 기준이다.

AI 생성 이미지의 한글·로고를 검증 없이 최종 브랜드 요소로 사용하지 않는다. 문구의 철자·누락·왜곡을 실제 출력에서 확인한다. 승인 대산 로고는 원본 자산으로 후처리하며 AI로 재생성하거나 대체하지 않는다.

## 5. 색상과 제품 이미지

색상은 웜화이트 배경, 블랙 제목·간판, 노란 핵심어 강조, 우드톤 보조 표현이라는 역할로 관리한다. 정확한 HEX·그라데이션·브러시 질감을 공식 수치로 임의 확정하지 않는다. 승인된 제작본의 값을 기록하더라도 해당 값의 적용 범위를 명시한다.

브랜드 색은 승인 로고 원본을 따른다. 공통 제작 지침에 기록된 승인 로고 실측값은 `#123628`이며, 이는 DoorMaster 전체 팔레트가 아니라 브랜드 자산 정확성에 관한 기준이다.

제품은 하단의 주요 시각 요소로 크게 배치한다. 실제 제품 사진·승인된 제품 reference를 우선 확인하고, 생성 외관을 실제 현장 시공 전후 사진이나 검증된 단면이라고 주장하지 않는다. 제품의 형상·비율·재질·성능을 디자인 목적으로 왜곡하지 않는다. 미확정 내부 구조·고정 방식·치수를 임의로 완성하지 않는다.

제품 일부의 화면 밖 잘림은 허용한다. 다만 주제를 판단하는 핵심 특징이 가려지거나 부자연스러운 절단처럼 보이면 수정한다. 실제 제품의 색이나 재질을 우드톤 팔레트에 맞추려고 바꾸지 않는다. 그림자와 두께감은 자연스럽게 유지하고 과장된 3D는 피한다.

## 6. 에피소드별 재사용

| 유형 | 구성 원칙 | QA 초점 |
|---|---|---|
| 비교형 | 비교 대상의 핵심 차이를 크게 표현 | 축척·각도·조명 등 비교 조건의 타당성, 핵심 차이 인지 |
| 설명형 | 대표 자재와 핵심 특징을 크게 표현 | 제품 종류와 특징 인지, 보조 컷·라벨의 과밀 방지 |
| 문제 해결형 | 문제 부위와 해결 결과를 중심으로 표현 | 문제 위치와 결과의 명료성, 손상·해결 효과 과장 방지 |

ABS도어, 문짝, 문틀, 문선, 도어 시공, 관련 자재에 동일한 시리즈 정체성을 적용한다. 두 제품, 좌우 병렬, 비교 화살표, 문선 폭 비교는 공통 필수 요소가 아니다. 해결 결과를 보여줄 때도 검증된 조건과 범위를 넘어 확언하지 않는다.

### 004편 사례 — 공통 고정 규칙이 아님

- 제목: 「기존 문틀, 슬림하게 바꿀 수 있을까?」
- 부제: 「일반 발포문틀 → 9mm 슬림 문선 리폼」
- 강조어: 「슬림하게」
- 표현 대상: 기존 넓은 문선과 슬림 문선 외관 비교
- MDF 9T는 해당 영상의 판재 두께 설정이다. 완성 문선 폭·벽면 대비 돌출량과 동일한 실측값으로 단정하지 않는다.

이 문구·제품·숫자를 다른 에피소드에 자동 적용하지 않는다. 최초 레퍼런스는 시각 기준이며, 후속 커버나 위치 조정본이 자동으로 최종 승인된 것은 아니다.

## 7. 출력·크롭 QA

다음은 사용자 지정 DoorMaster 전용 제작 기준이다. 플랫폼의 모든 기기·업로드 화면에서 동일한 표시를 보장하는 공식 규격으로 단정하지 않는다.

| 대상 | 크기·중앙 범위 | 검사 구분 |
|---|---|---|
| 릴스 원본 | 1080×1920 PNG, 9:16 | 원본 디자인 품질 필수 |
| Instagram 프로필 그리드 | 1080×1440, 3:4 / y=240~1680 | 필수 QA |
| 피드 미리보기 | 1080×1350, 4:5 / y=285~1635 | 추가 QA |
| 정사각 호환성 | 1080×1080, 1:1 / y=420~1500 | 선택적 검사 |

중앙 3:4에서 시리즈명·메인 제목·핵심 제품 이미지의 가독성을 직접 확인한다. 의미 이해에 필요한 부제·라벨도 확인한다. 4:5 결과는 별도로 기록하며, 1:1 FAIL만으로 커버를 자동 불합격 처리하지 않는다. 실제 플랫폼 업로드 미리보기는 별도 확인한다.

크롭 가독성과 9:16 원본 디자인 완성도는 서로 독립적으로 평가한다. 크롭 PASS가 원본 디자인 PASS를 대신하지 않는다. 크롭 대응을 이유로 전체를 작은 정보 카드로 재배열하거나 제품 비중을 지나치게 줄이지 않는다. 필요한 위치 조정은 최소 범위로 하고 새 버전으로 저장한다.

### 원본과 크롭의 품질 판정

- **PASS:** 해당 검사에서 필수 문구와 핵심 특징이 읽히고, 구도와 합성이 자연스럽다.
- **WARN:** 의미를 해치지 않는 장식 일부의 잘림 등 제한 사항이 있다. 영향과 사용 범위를 기록한다.
- **FAIL:** 시리즈명·핵심 제목·제품 특징이 잘려 이해를 방해하거나, 배경 이음선·합성 패치 등으로 원본 품질이 손상된다. 검사 대상을 명시하고 수정 또는 사용자 판단 대상으로 보고한다.
- 필수 3:4, 원본 품질, 추가 4:5, 선택 1:1의 결과를 각각 기록한다. 미검증 항목은 PASS로 표시하지 않는다.

확인 항목은 과도한 상단 공백, 배경 연장의 수평 이음선, 합성된 직사각형 배경 패치, 제목·간판 잘림, 제품의 부자연스러운 잘림, 핵심 제품 특징, 모바일에서의 시각적 균형이다. 장식 일부의 잘림과 글자·제품 핵심부의 잘림을 구분한다. 레퍼런스와 나란히 비교하고 모바일 축소 화면도 직접 확인한다.

## 8. 브랜드와 크롭 제외 처리

승인된 대산 심볼과 정확한 표기 **DAESAN / 대산종합건축자재**만 사용한다. 승인 자산의 색·종횡비를 유지하고 AI 생성 로고로 대체하지 않는다. 사용 프로젝트의 승인 자산을 확인하고 출처와 버전을 기록한다. 공식 확인되지 않은 영문 슬로건이나 임의 회사명을 추가하지 않는다.

브랜드는 화면 하단에 작고 절제되게 배치하되 확인 가능한 가독성을 확보한다. 일반 COVER.md의 브랜드 좌표·크기를 이 시리즈에 강제하지 않는다. 가독성 보정을 위해 눈에 띄는 카드나 배경 패치를 붙이지 않는다.

크롭에서 대산 브랜드가 제외되면 **WARN으로 기록하고 사용자 개별 승인을 받는다.** 시리즈명·제목·제품의 크롭 PASS와 별개로 처리한다. 특정 커버의 승인을 시리즈 전체의 브랜드 생략 자동 허용으로 확대하지 않는다. 9:16 원본에는 승인 브랜드를 유지한다.

## 10. 제작·승인·보존

1. 최신 사용자 지시, 영상과 커버의 승인 상태, 해당 에피소드 기록을 확인한다. 일반 운영은 최종 영상 승인 뒤 커버를 별도 제작하며, 명시적으로 승인된 작업 범위를 따른다.
2. 최초 레퍼런스와 본 가이드로 독립 디자인을 구성한다. 공통 문서는 운영 원칙 확인에만 사용한다.
3. 에피소드 유형·제목·부제·강조어·제품 reference를 정하고 확인되지 않은 사실을 구분한다.
4. 승인 자산을 우선 재사용한다. 새 이미지 생성은 사용자 요청·승인 범위에서만 진행한다.
5. 제목·부제 등 교체 요소를 편집 가능한 레이어로 구성하고 실제 사용 폰트·자산을 기록한다.
6. 원본 품질, 필수 3:4, 추가 4:5, 필요 시 선택 1:1, 모바일 가독성과 브랜드를 각각 QA한다.
7. 버전 결과물과 QA를 보고하고 사용자 승인을 기다린다. 문서 승인·커버 승인·브랜드 크롭 제외 승인은 구분한다.
8. 승인본, 크롭 QA, 편집 소스, 직접 참조 제품·로고·폰트, 자산 출처와 승인 기록을 보존한다.

커버는 프로젝트 `public/covers/`, 크롭 QA는 `public/covers/qa/`에 저장한다. 기존 파일은 보존하고 삭제·이동은 별도 명시 승인 없이 하지 않는다. 코드 미참조나 후보 파일명만으로 삭제 가능하다고 판단하지 않는다. 이 문서는 Git commit/push 권한을 부여하지 않는다.

추가로 대체한 과거 항목:

- 일반 커버의 박스 좌표, 60px 제목·92px 행간, 78px 로고 등은 DoorMaster 규격에서 제외했다.
- Pretendard 강제, 마지막 줄만 강조, 동일 정렬 좌표 반복, 이미지 영역만 교체하는 방식은 독립 시각 위계와 가변 요소 원칙으로 대체했다.
- 「레퍼런스 경로를 찾지 못함」은 과거 조사 상태다. 이미지 경로는 확인됐지만 원본의 실제 폰트·분리 편집 소스·정식 색상 토큰이 확인됐다는 의미는 아니다.
- 「두 문틀」「문선 폭 비교」「9mm·MDF 9T」「기존 문틀, 슬림하게 바꿀 수 있을까?」는 004편 사례로 한정했다.
- 「크롭 브랜드 제외는 별도 보고」를 WARN 및 사용자 개별 승인으로 명확히 했다.
- 「이번 작업에서는 이미지 생성하지 않음」 같은 일회성 실행 제한은 반복 제작 규칙에서 제외했다. 실제 작업 범위는 각 사용자 지시로 결정한다.
- 중앙 크롭을 맞추기 위한 전체 하향 이동은 시리즈 공통 처방이 아니다. 과도한 상단 공백·수평 이음선·브랜드 패치가 발생하면 원본 품질 QA에서 별도 판정한다.

## 13. 등록과 남은 확인 사항

이 문서는 DoorMaster 시리즈용 ChatGPT 프로젝트 공통 소스로 사용할 수 있다. 최초 레퍼런스 이미지도 함께 제공해 시각 기준을 유지한다. 전체 대산 커버 공통 디자인을 대체하는 문서로 등록하지 않는다.

사용자 최종 문서 확인 전에는 검토 상태를 표시한다. 실제 폰트·편집 가능한 간판/아이콘 자산·제작 색상값은 확인·기록 후 해당 결과물의 시각 승인을 받는다. 이를 레퍼런스의 공식 원본 규격으로 소급해 주장하지 않는다. 개별 커버 승인, 크롭 브랜드 제외 승인, 실제 업로드 화면 검증은 별도로 남긴다.
