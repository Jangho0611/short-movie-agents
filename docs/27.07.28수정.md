## 7. 최종 영상 조립

- `assemble_final_movie.ps1` 추가
- 세션 경로 직접 입력 방식 지원
- 매개변수 생략 시 최신 정상 세션 자동 선택
- `scene_*.mp4`를 장면 번호의 숫자 순서로 정렬
- 재인코딩 없이 `-c copy` 방식으로 `final_movie.mp4` 생성

기본 실행:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\assemble_final_movie.ps1
```

세션 경로를 직접 지정:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\assemble_final_movie.ps1 -SessionFolder "output\세션ID"
```
