## 3. TTS 기준

### 확정 방향
- 한국어 남성 현장형 숏폼 나레이션
- 빠르고 경쾌함
- 실제 현장을 보고 말하는 듯한 느낌
- 차분한 다큐멘터리 / 광고 아나운서 톤 지양
- 현재 테스트에서는 Gemini TTS Fenrir 계열이 비교적 적합

### 중요 운영 원칙
TTS는 반드시 먼저 생성 → 청취 → 승인한다.

승인된 TTS는 이후 영상·자막 수정 과정에서 절대 다시 생성하지 않는다.

영상 길이는 승인된 TTS의 실제 발화 길이를 기준으로 구성한다.

- 실제 길이 약 7.18초

## 4. TTS 실패 사례

### 실패 1
문장을 여러 개로 나누어 Gemini TTS를 반복 생성하면서
목소리·톤·발화 느낌이 달라짐.

### 실패 2
전체 TTS라고 판단한 파일이 실제로는
"오늘도 25톤 한 차 들어왔어요"까지만 포함되어
영상 후반 음성이 잘리는 문제가 발생.

### 개선
최종 제작 전 TTS 파일을 반드시 처음부터 끝까지 직접 청취한다.

ffprobe 길이만 보고 정상 여부를 판단하지 않는다.

승인 후 TTS 파일은 LOCK 상태로 취급한다.

---

## 5. 영상 제작 실패 사례

### FFmpeg 단일 명령 과도한 결합
자막 PNG loop + 영상 + TTS + 엔딩을
한 번의 긴 FFmpeg 명령으로 처리하면서
수십 분 길이로 무한 렌더에 가까운 현상 발생.

### 개선
각 단계를 분리한다.

1. 본편
2. TTS
3. 자막
4. 엔딩
5. 최종 결합

수정 시 전체를 다시 만들지 않고
변경된 부분만 다시 렌더한다.

---

## 6. 자막 실패 사례

### Retina PNG 문제
macOS NSImage 방식으로 만든 자막 PNG가
의도한 픽셀보다 2배 크게 생성되어
1080×1920 화면 밖으로 글자가 잘려 나감.

### 개선
자막 PNG를 사용할 경우 실제 pixelWidth / pixelHeight를 확인한다.

하지만 현장형 숏폼에서는 앞으로
정적인 PNG 자막보다 Remotion 자막 모션을 우선 사용한다.

## 7. Remotion 자막 테스트 결과

Remotion이 현장형 숏폼 자막에 더 적합하다고 판단.

가능한 효과:
- 한글 완성형 글자별 타이핑
- 글자별 POP

- 중앙에서 크게 튀어나오는 펀치 자막
- 핵심어 확대
- 핵심어 색상 강조
- 짧은 흔들림
- 두 번 펄스
- 슬라이드 / 바운스
- Glow
- Flash
- Spark
- 불꽃 터짐

## 8. 현재 선호하는 Instagram Reels 자막 방향

자막은 단순한 정보 전달용이 아니라
영상 리듬을 만드는 그래픽 요소로 사용한다.

### 기본 원칙
- 1080×1920 프레임
- 이미지 일부를 자막이 가리는 것은 허용
- 자막은 크고 눈에 띄게 사용 가능
- 단, 화면 프레임 밖으로 절대 나가지 않는다
- 최대 2줄
- 초굵은 한글 고딕
- 적당한 검정 외곽선 + 그림자
- 글자 자체의 가독성 최우선
- 깨진 글씨처럼 보이는 과도한 외곽선 금지

### 모션
영상마다 한 가지 효과만 고정하지 않는다.

최근 Instagram Reels 스타일을 참고하여
콘텐츠와 TTS 리듬에 따라 다양한 효과를 조합한다.

예:
- 한 글자씩 팍팍 등장
- 단어별 POP
- 중앙 펀치
- scale 80% → 115% → 100%
- 짧은 rotation
- keyword shake
- pulse
- slide
- spark
- fire burst
- flash
- glow

효과는 짧고 강하게 사용한다.

- 변경된 레이어만 수정
- Remotion cache 활용
- 자막 스타일은 재사용 가능한 프리셋으로 발전
